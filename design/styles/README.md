# 视觉方向探索（4 选 1）

四份稿子渲染同一屏：人物卡头部 + 属性/豁免/技能 + 法术位/法术/特性（含嵌套）+ 战斗条（先攻、行动、日志）。
直接用浏览器打开 `01-…04-*.html`，右上角「切换明 / 暗」可看两套主题。字体全部来自 Google Fonts，宽 1400 与 1024 均已检查。

## 01 典籍 · 朱批手抄本 (`01-codex.html`)
手抄本 / 中式书册：羊皮纸、朱砂红做标题与强调、金色只做细节。面板用双线框，标题带 ❦ 与细双线，属性是盾形徽章，人物名前有朱印，法术位是红蜡丸。
- 明：纸 `#eadfc4` / 面 `#f7efd9` / 墨 `#2a1e12` / 朱 `#8b2a1b` / 金 `#a47c22`。暗：`#14100b` / `#1d1710` / `#eadfc2` / `#d9694d` / `#d4ab52`（烛光下的旧书）。
- 字体：Noto Serif SC（标题、名字、法术名）+ Noto Sans SC（正文）+ EB Garamond（数字）。
- 质感：SVG 噪点纸纹、双线框、角标、菱形点；无阴影无渐变（除头部淡渐变）。密度：中高。
- 弱项：装饰最多，页面最「重」；窄屏徽章属性会变形，需要降级成方块；朱红同时表示强调和伤害，要靠色相微调区分。

## 02 暖灰工具 · 现代界面 (`02-warm-modern.html`)
Linear / Notion 式：暖灰底、白卡片、圆角 12px、柔阴影，只用一个赤陶色强调。信息靠字重与留白分层，不靠装饰。
- 明：`#f5f3ef` / `#ffffff` / `#25221e` / 赤陶 `#c4502d`。暗：`#151412` / `#1d1c19` / `#f0ece4` / `#ee8a66`。
- 字体：Noto Sans SC 全线 + Inter（数字）。AC 做成深色实心块作视觉锚点。
- 质感：无纹理，仅柔阴影与淡底色块。密度：高，最省空间。
- 弱项：最没有「龙与地下城」气质，和任何后台工具长得像；用户说过「太冷、太空」，这一方向最容易回到那里。

## 03 奥术魔典 · 暗色优先 (`03-grimoire.html`)
法师的魔典：靛黑底、金色细线与角标、紫色魔焰做强调、青色做「有效 / 已熟练」。属性是切角铭牌，法术位是发光菱形，当前回合有光晕。
- 暗（默认）：`#0b0912` / `#14111f` / `#e9e4f7` / 紫 `#a98bff` / 金 `#e0be72` / 青 `#5fd9c8`。明（月光纸）：`#e7e4ee` / `#f6f4fb` / `#1d1830` / `#5a3cb4` / `#8f6b17`。
- 字体：Noto Serif SC（标题，字距拉开）+ Noto Sans SC（正文）；数字用 Noto Serif SC（试过 Cinzel / Marcellus，「1」像 I、「0」像 O，不适合看数）。
- 质感：渐变光晕背景、发光描边、切角。密度：中高。
- 弱项：发光与彩色强调在大量数字下易疲劳；明色主题只是「换皮」，气质损失大；晚上桌游气氛好，白天投屏不佳。

## 04 桌游卡牌 · 粗描边 (`04-boardgame.html`)
桌游说明书 / 卡牌：2.5px 深色描边、硬阴影、饱和平涂色块（番茄红、芥黄、青、紫），面板标题是彩色标签条，标签像贴纸，按钮可「按下」。
- 明：奶油 `#f8e9c1` / 面 `#fffaec` / 墨 `#1e1a2e` + 番茄 `#e4492f`、芥黄 `#f5b82e`、青 `#169e92`、紫 `#7b4fd8`。暗：深靛 `#171430` / `#252046` / 奶油描边 `#f3e5bd`。
- 字体：Noto Sans SC 700–900（粗黑）+ Rubik（数字）。
- 质感：圆点网格背景、硬阴影、轻微旋转的标签。密度：中（描边吃空间），但分区最清楚。
- 弱项：视觉噪声最大，十几个彩色标签同屏时会花；气质偏轻快，战斗的紧张感弱；颜色已被分区占用，语义色（伤害红）要另加规则。

## 推荐
**以 01 典籍为骨架、吸收 02 的留白节奏**：它最贴合「私人战桌、朋友聚会」的人情味，也正面回答了「太冷、太空」；其装饰全是 CSS（纹理、双线、角标），不增加信息负担，数字仍用清晰的衬线。若更看重密度和长时间使用的舒适，选 02。03 适合做「夜间模式」的独立暗色皮肤，04 适合做桌游屏 / 投屏的特别主题。

# 任务 F436：巨武器大师

- 条目键：`XPHB:巨武器大师`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【重武器掌握】
在你的回合内，你的攻击动作中，当你用具有H词条的武器命中了一名生物时，你可以让这把武器对目标额外造成一定的伤害，额外伤害等同于你的熟练。
【砍伐者】
当你使用近战武器掷出一次重击时，或当你用其将一个生物的生命值降低至 0 时，你可以立即使用你的附赠动作用同一把武器发动一次攻击。

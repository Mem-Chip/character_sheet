# 任务 F461：神射手

- 条目键：`XPHB:神射手`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【绕过掩体】
你使用武器发动的远程攻击无视掩护和掩护。
【抵近射击】
位于一个敌人 5 尺范围内的情况下，你使用远程武器发动的攻击检定不会因此具有劣势。
【百步穿杨】
使用远程武器攻击超出常规射程的目标时，你的攻击检定不会因此具有劣势。

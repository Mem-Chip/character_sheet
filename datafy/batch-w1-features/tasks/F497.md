# 任务 F497：诡诈攻击

- 条目键：`XPHB:诡诈攻击`
- 出处：可选特性（战斗大师的战技）

## 原文

以一个附赠动作，你可以消耗一枚卓越骰并指定一个位于你 5 尺范围内的生物为目标，对其虚晃一招。你在本回合内对该生物发动的下一次攻击检定具有优势。如果该攻击命中，则将消耗的卓越骰加在此次攻击的伤害掷骰中。

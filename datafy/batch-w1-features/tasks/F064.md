# 任务 F064：驱散亡灵

- 条目键：`XPHB:牧师:驱散亡灵:2`

## 原文

以一个魔法动作，你展现圣徽，斥退诸亡灵生物。你30尺内每个由你选择的亡灵都必须进行一次感知豁免，失败则陷入恐慌和失能状态，持续一分钟。在这段持续时间内，被驱散的生物会尽可能远离你。此效应在其受到伤害时提前结束，你陷入失能状态或是死亡也会结束此效应。

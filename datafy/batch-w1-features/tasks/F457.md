# 任务 F457：仪式施法者

- 条目键：`XPHB:仪式施法者`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【仪式魔法】
你选择数道具有仪式标签的一环法术，其具体数量等于你的熟练。你始终准备着这几道法术，并可以用你拥有的任何法术位去施展它们。施展它们的施法属性为你用此专长提升的属性。此后，每当你的熟练提升时，你可以通过这个特性多获得一道始终准备的、带有仪式标签的一环法术。
【快速仪式】
你可以用通常的施法时间来施展一道仪式法术，而不需要仪式的延长施法时间。这么做不会花费你的法术位。一旦你通过这种方式施展了一道法术，直到完成一次长休前你都不能再使用这个增益。

# 任务 F476：战地施法者

- 条目键：`XPHB:战地施法者`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【专注】
你为维持专注的所做的体质豁免具有优势。
【响应法术】
当一个生物因离开你的触及范围而引发你的借机攻击时，你能使用你的反应来对这个生物施展一道法术，而非发动一次借机攻击。这道法术的施法时间必须为动作，且必须将该生物选为法术的唯一目标。
【姿势成分】
即使你的一只手或双手上都有武器/盾牌，你也能满足法术的姿势成分要求。

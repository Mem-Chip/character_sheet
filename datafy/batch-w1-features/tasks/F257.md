# 任务 F257：妖精漫游者法术

- 条目键：`XPHB:游侠:妖精漫游者法术:3`

## 原文

当你到达妖精漫游者法术表中特定的游侠等级时，你就始终准备着表中对应的法术。
【妖精漫游者法术】
| 游侠等级 | 法术 |
| 3环 | 魅惑类人 |
| 5环 | 迷踪步 |
| 9th | 妖精召唤术 |
| 13th | 任意门 |
| 17th | 假象术 |
你还获得了一种妖精祝福。你可以在下方精野之赐表中选择你的祝福或者随机决定它。
【精野之赐】
| 1d6 | 赠礼 |
| 1 | 当你进行短休或长休时，缥缈的蝴蝶在你周身振翅。 |
| 2 | 每天拂晓时分，花朵从你的发间盛放。 |
| 3 | 你身上有淡淡的肉桂、薰衣草或肉豆蔻，或另一种令人舒适的药草或香料的香味。 |
| 4 | 你的影子会在没人直视它时起舞。 |
| 5 | 你的头发中长出纤细的触角或鹿角。 |
| 6 | 你的肤色和发色会在每个拂晓时改变。 |

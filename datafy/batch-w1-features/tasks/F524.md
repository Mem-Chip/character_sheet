# 任务 F524：反击

- 条目键：`XPHB:反击`
- 出处：可选特性（战斗大师的战技）

## 原文

当一个生物对你发动了一次近战攻击检定但失手时，你可以执行一个反应并消耗一枚卓越骰使用武器或徒手打击对其发动一次近战攻击检定。如果该攻击命中，则将卓越骰加在此攻击的伤害掷骰中。

## 职业表（20 级那一行；`classTable('列名')` 读的是角色当前等级那一行）

- 回气：4
- 武器精通：6

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `回气`：回气
- `动作如潮`：动作如潮
- `卓越骰`：卓越骰

## 人物卡数据里的备注（只是给人看的文字，**没有任何效果**；里面提到的战斗中的效果需要你写）

- 生物对你发动的近战攻击检定失手时，可执行一个反应并消耗一枚卓越骰，用武器或徒手打击对其发动一次近战攻击检定

## 补充

- 战技消耗卓越骰：`cost: [{ resource: '卓越骰' }]`。
- 卓越骰的大小随战士等级变：`cond(self.levelOf('战士') >= 18, 1d12, cond(self.levelOf('战士') >= 10, 1d10, 1d8))`。
- 战技的豁免 DC = 8 + 熟练加值 + 力量或敏捷调整值（取高）：`8 + self.pb + max(self.mod.str, self.mod.dex)`。

# 任务 F441：拦截

- 条目键：`XPHB:拦截`
- 出处：专长（战斗风格专长）

## 原文

当一名你可见的生物以攻击检定命中你 5 尺内的另一名生物，你能够以反应减少对目标造成的伤害，使该伤害降低1d10 + 你的熟练。你必须持握着一面盾牌或者一把简易/军用武器才能使用这个反应。

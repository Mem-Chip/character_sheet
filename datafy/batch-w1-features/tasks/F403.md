# 任务 F403：演员

- 条目键：`XPHB:演员`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【伪装】
当你伪装成某个虚构或真实的个体时，你为使别人相信你就是那个个体所做的欺瞒或表演的魅力检定具有优势。
【拟声】
你可以模仿其他生物发出的声音，包括说话声。听到这种模仿的生物必须成功通过一次感知（洞悉）检定，才能察觉出该效果是伪造的（DC 8 = 你的魅力调整值 +熟练）。

# 任务 F516：链之魔契

- 条目键：`XPHB:链之魔契`
- 出处：可选特性（魔契师的魔能祈唤）

## 原文

你习得法术寻获魔宠且能以一个魔法动作施展它，且无需消耗法术位。
每当你施展该法术，并为你的魔宠选择形态时，除了通常的形态选项，你还可以改为选择下列特殊形态之一：小魔鬼、伪龙、小恶魔、骷髅、史拉蟾蝌蚪、求索斯芬克斯、小仙灵，或毒蛇（魔宠的数据见附录B）。
此外，当你执行攻击动作时可以放弃自己动作攻击中的一次攻击，转而让你的魔宠使用其反应发动一次攻击。

# 任务 F425：粉碎者

- 条目键：`XPHB:粉碎者`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【推离】
每回合一次，当你以造成钝击伤害的一次攻击命中了一个生物时，只要这个生物的体型不比你大超过一级，你就能将它移动 5 尺至一处未占据空间中。
【强化重击】
当你掷出一次重击命中一名生物并对其造成钝击伤害后，直到你的下个回合开始前，任何以该生物为目标的攻击检定都会具有优势。

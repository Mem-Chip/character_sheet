# 任务 F530：转化法术

- 条目键：`XPHB:转化法术`
- 出处：可选特性（术士的超魔法）

## 原文

当你施展一道造成以下列表中某一种类型伤害的法术时，你可以使使用1术法点将法术的该种伤害类型转换为列表中的另一种伤害类型：强酸、冷冻、火焰、闪电、毒素、雷鸣。

## 职业表（20 级那一行；`classTable('列名')` 读的是角色当前等级那一行）

- 术法点：20
- 戏法：6
- 准备法术：22
- 1环：4
- 2环：3
- 3环：3
- 4环：3
- 5th：3
- 6th：2
- 7th：2
- 8th：1
- 9th：1

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `sorcery_points`：术法点
- `先天术法`：先天术法

## 人物卡数据里的备注（只是给人看的文字，**没有任何效果**；里面提到的战斗中的效果需要你写）

- 施展造成指定类型伤害的法术时，可消耗1术法点将伤害类型转换为强酸/冷冻/火焰/闪电/毒素/雷鸣中的另一种

## 补充

- 超魔法消耗术法点：`cost: [{ resource: 'sorcery_points', n: <点数> }]`。超魔法改的是「下一个施展的法术」，引擎还没有改写法术的机制，通常写成 manual 并说明。

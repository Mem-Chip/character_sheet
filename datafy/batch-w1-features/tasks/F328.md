# 任务 F328：时械法术

- 条目键：`XPHB:术士:时械法术:3`
- 出处：术士 3 级（时械术法）

## 原文

当你到达时械法术表中特定的术士等级时，你就始终准备着表中对应的法术。
【时械法术】
| 术士等级 | 法术 |
| 3 | 援助术，警报术，次等复原术，防护善恶 |
| 5 | 解除魔法，防护能量 |
| 7 | 行动自如，构装召唤术 |
| 9 | 高等复原术，力场墙 |
此外，你可以从秩序显迹表格中选择或掷骰决定一种你在施法时显现出与秩序之联系的方式。
【秩序显迹】
| 1d6 | 显迹 |
| 1 | 幽灵般的虚幻齿轮在你身后旋转。 |
| 2 | 时钟的指针出现在你的眼中。 |
| 3 | 你的皮肤发出如黄铜般的金属光泽。 |
| 4 | 你的体表浮动着方程式和几何图形。 |
| 5 | 你的法器短暂地变化成小巧的机械装置。 |
| 6 | 你和那些受到你法术影响的生物都会听到齿轮的滴答声或是钟表的响铃。 |

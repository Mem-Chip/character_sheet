# 任务 F269：猎杀技艺

- 条目键：`XPHB:游侠:猎杀技艺:3`
- 出处：游侠 3 级（猎人）

## 原文

你选择并获得以下特性选项之一。当你完成一次短休或长休时，你可以将所选的选项替换为另一个。
【巨像屠夫】
你强而有力的攻击可以击倒最强壮的对手。当你用武器命中生物时，如果该敌人生命值不满，则该武器额外对目标造成1d8点伤害。你每回合只能造成一次这种额外伤害。
【灭族者】
每个你的回合一次，当你用武器进行攻击时，你可以用该武器对位于目标5尺内的另一生物发动另一次攻击。额外攻击的目标必须处于你武器射程或范围内，且是你这回合没有攻击过的目标。

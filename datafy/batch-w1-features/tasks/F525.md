# 任务 F525：追踪法术

- 条目键：`XPHB:追踪法术`
- 出处：可选特性（术士的超魔法）

## 原文

当你为一道法术进行一次攻击检定并未命中时，你可以使用1术法点重投那个d20。你必须使用重投的结果。
即使你已经在一道法术上使用了其他超魔，你仍然可以使用追踪法术。

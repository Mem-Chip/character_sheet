# 任务 F475：徒手战斗

- 条目键：`XPHB:徒手战斗`
- 出处：专长（战斗风格专长）

## 原文

当你使用徒手打击命中并造成了伤害时，你可以改为造成1d6 + 你的力量调整值点钝击伤害，而非原本的徒手打击伤害。如果你进行攻击检定时并没有持握任何武器与盾牌，则上述伤害中的d6将变为d8。
每当你的回合开始时，你还可以对一个因你受擒的生物造成1d4点钝击伤害。

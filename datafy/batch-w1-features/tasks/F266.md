# 任务 F266：追猎如风

- 条目键：`XPHB:游侠:追猎如风:11`
- 出处：游侠 11 级（幽域追踪者）

## 原文

你的恐惧打击造成的心灵伤害变为2d8。另外，当你使用恐惧伏击的恐惧打击特性时，你可以创造出以下的额外效应之一。
【瞬息打击】
你可以用同一把武器，对位于原目标5尺范围内的另一生物再发动一次攻击，新目标必须处于你武器的触及或射程内。
【群慌】
目标与位于目标10尺范围内的每个生物都必须通过一次对抗你法术豁免DC的感知豁免。若豁免失败，生物将会陷入恐慌状态，持续至你的下一回合开始。

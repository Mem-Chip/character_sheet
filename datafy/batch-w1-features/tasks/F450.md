# 任务 F450：音乐家

- 条目键：`XPHB:音乐家`
- 出处：专长（起源专长）

## 原文

你获得以下增益。
【乐器训练】
你获得三种自选的乐器的熟练。
【鼓舞之歌】
作为你完成短休或长休的一部分，你可以用你熟练的乐器演奏一首歌曲，并令听到这首乐歌的盟友获得英雄激励。以这种方式所能影响的盟友数量最多等于你的熟练。

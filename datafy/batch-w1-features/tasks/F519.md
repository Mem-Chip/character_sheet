# 任务 F519：精准攻击

- 条目键：`XPHB:精准攻击`
- 出处：可选特性（战斗大师的战技）

## 原文

当你的一次攻击检定失手时，可以消耗一枚卓越骰并将其结果加在本次攻击的攻击检定中，这可能会导致其命中。

- 攻击检定失手时，可消耗一枚卓越骰并将其结果加在该次攻击检定中，这可能导致其命中

- 战技消耗卓越骰：`cost: [{ resource: '卓越骰' }]`。

# 任务 F444：巫师杀手

- 条目键：`XPHB:巫师杀手`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【专注中断手】
当你对一名正处于专注中的生物造成伤害时，该生物为维持本次专注所做的豁免检定时具有劣势。
【审慎护心】
当你的智力、感知或魅力豁免失败时，你可以将其改为成功。此增益一经使用，直到完成短休或长休前你都无法再次使用。

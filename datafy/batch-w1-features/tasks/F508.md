# 任务 F508：灵动攻击

- 条目键：`XPHB:灵动攻击`
- 出处：可选特性（战斗大师的战技）

## 原文

你以攻击检定命中一个生物时，可以消耗一枚卓越骰以让战友移动到更有利的位置。将所消耗的卓越骰加在此次攻击的伤害掷骰中，并指定一个能看见你或听到你声音的自愿生物。该生物可以用其反应移动至多等于其速度一半的距离。本次移动不会引发本次所攻击目标的借机攻击。

- 卓越骰的大小随战士等级变：`cond(self.levelOf('战士') >= 18, 1d12, cond(self.levelOf('战士') >= 10, 1d10, 1d8))`。
- 战技的豁免 DC = 8 + 熟练加值 + 力量或敏捷调整值（取高）：`8 + self.pb + max(self.mod.str, self.mod.dex)`。

# 任务 F151：施法

- 条目键：`XPHB:战士:施法:3`
- 出处：战士 3 级（奥法骑士）

## 原文

你学会了如何施展法术。施法规则见第七章。下文将详述如何将这些规则应用于奥法骑士。
【戏法】
你知晓两道你从法师法术列表中选择的戏法。推荐选择冷冻射线和电爪。每当你获得一个战士等级时，你都能从此特性的戏法中选择其一替换为另一道你从法师法术列表中选择的戏法。
当你的战士等级到达10级时，你能另选一道法师戏法并习得。
【法术位】
奥法骑士施法表显示了你可用于施展一环及以上法术的法术位数量。你在完成一次长休时恢复所有已消耗的法术位。
【1环及以上的准备法术】
你准备可供你以此特性施展的一环及更高环阶的法师法术列表。为此，选择三道来自法师法术列表的法术。推荐选择燃烧之手、跳跃术和护盾术。
已准备法术数量会随你战士等级的提升而增加，如奥法骑士施法表中的准备法术一列所示。每当这一列的数字增加时，从法师法术列表中选择额外法术准备，直至已准备法术的数量与表格中的数字一致。你所选择法术的环阶必须是你所拥有法术位对应的环阶。
【更换你的准备法术】
每当你获得一个战士等级，就可以将你准备列表上的一道法术替换为另一道法师法术，你必须拥有替换后法术对应环阶的法术位才可以替换。
【施法属性】
你法师法术的施法属性是智力。
【法器】
你可以使用奥术法器作为你法师法术的法器。

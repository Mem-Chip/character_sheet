# 任务 F415：强力恢复之恩惠

- 条目键：`XPHB:强力恢复之恩惠`
- 出处：专长（史诗恩惠）

## 原文

你获得以下增益。
【背水一战】
当你的生命值将要降至 0 时，你可以改为降至 1 生命值并恢复等于你生命值上限一半的生命值。该增益一经使用，直到完成长休你都无法再次被使用。
【重获生机】
你获得一个有着十枚d10的治疗池。以一个附赠动作，你可以消耗治疗池中任意枚骰子来恢复你的生命值。投掷全部你消耗的骰子，将掷骰结果相加，即是你以此恢复的生命值。当你完成长休时，你的治疗池重获所有被消耗的骰子。

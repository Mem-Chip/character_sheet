# 任务 S175：解除魔法

- 条目键：`XPHB:spell:解除魔法`
- 出处：3 环法术
- 3 环；施法时间：1 动作；距离：120 尺；持续时间：立即

## 原文

在施法距离内指定一名生物、一个物件或一处魔法效应。所有影响该目标的三环或更低环阶法术即告终止。每个影响目标的四环或更高环阶法术都需要以你的施法属性进行一次属性检定（DC 10加上该法术的环阶），检定成功时目标法术终止。

## 升环

【升环施法】
你直接终止影响目标的小于等于该施法环阶的法术效应。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

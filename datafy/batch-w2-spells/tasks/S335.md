# 任务 S335：虹光喷射

- 条目键：`XPHB:spell:虹光喷射`
- 出处：7 环法术
- 7 环；施法时间：1 动作；距离：60 尺；持续时间：立即

## 原文

八条光线从你的手上闪出，作用于 60 尺锥状 [效应区域]范围。每名位于锥状 [效应区域]之中的生物进行一次敏捷豁免。为每个目标掷一次1d8来决定影响到它的射线种类，参照虹光射线表。
【虹光射线】
| 1d8 | 射线 |
| 1 | 红色。 豁免失败： 12d6 火焰伤害。豁免成功： 半伤。 |
| 2 | 橙色。 豁免失败： 12d6 强酸伤害。豁免成功： 半伤。 |
| 3 | 黄色。 豁免失败： 12d6 闪电伤害。豁免成功： 半伤。 |
| 4 | 绿色。 豁免失败： 12d6 毒素伤害。豁免成功： 半伤。 |
| 5 | 蓝色。 豁免失败： 承受12d6寒冷伤害。豁免成功： 半伤。 |
| 6 | 靛色。豁免失败：目标陷入束缚状态，且其每个回合结束进行一次体质豁免。在累计三次豁免成功后，状态终止。在累计三次豁免失败后，该生物被转化为石头陷入石化状态，直到此状态被高等复原术或类似效应解除为止。成功或失败的检定不需要连续；只要记录各情况的次数直至其中一方累计三次为止。 |
| 7 | 紫色。 豁免失败： 目标陷入目盲状态且在下一个你的回合开始时进行一次感知豁免。豁免成功，状态终止。豁免失败，状态终止，且该生物会被传送到另一个存在位面（由DM选择）。 |
| 8 | 特殊。 目标被两道射线击中。掷两次骰，若有骰子出目为8则重骰那颗骰子。 |

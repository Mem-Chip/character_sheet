# 任务 S352：操控天气

- 条目键：`XPHB:spell:操控天气`
- 出处：8 环法术
- 8 环；施法时间：10 分钟；距离：5 miles；持续时间：8 小时（专注）

## 原文

你在法术持续时间内操控距你 5 里内的天气。你在施法时必须位于户外，并且若你回到室内，法术会提前终止。
你施展此法术时，可以改变现有的天气状况（由DM决定）。你可以改变降水、气温和风势。新状况需要1d4 × 10分钟才能起效。一旦新状况起效，你便能再次改变天气状况。法术结束时，天气状况会逐渐回归正常。
改变天气状况时，你可以从以下表格查明与目前对应的等级，再选择同一表格中高一级或低一级的状况作为其改变结果。改变风势时，你还可以同时改变其风向。
【降水】
| 等级 | 状态 |
| 1 | 天晴 |
| 2 | 薄云 |
| 3 | 多云，有雾 |
| 4 | 有雨，冰雹，有雪 |
| 5 | 暴雨，冰暴，暴雪 |
【气温】
| 等级 | 状态 |
| 1 | 酷热 |
| 2 | 炎热 |
| 3 | 暖和 |
| 4 | 清凉 |
| 5 | 寒冷 |
| 6 | 冻结 |
【风势】
| 等级 | 状态 |
| 1 | 无风 |
| 2 | 和风 |
| 3 | 强风 |
| 4 | 狂风 |
| 5 | 风暴 |

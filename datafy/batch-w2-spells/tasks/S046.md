# 任务 S046：光导箭

- 条目键：`XPHB:spell:光导箭`
- 出处：1 环法术
- 1 环；施法时间：1 动作；距离：120 尺；持续时间：1 轮

## 原文

你向施法距离内的一名生物掷出一道光箭。对目标进行一次远程法术攻击。命中时，目标受4d6点光耀伤害。在你下个回合结束前，对目标发动的下一次攻击检定具有优势。

## 升环

【升环施法】
使用的法术位每比一环高一环，此法术的伤害就增加1d6点。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

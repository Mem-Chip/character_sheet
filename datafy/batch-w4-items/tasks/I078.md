# 任务 I078：飞毯（3尺×5尺）

- 条目键：`XDMG:item:飞毯（3尺×5尺）`
- 出处：魔法物品（非常珍稀）

## 原文

你可以用一个魔法动作，说出飞毯的命令词来让它起飞或悬停。只要你在飞毯周围30尺内，它就会按照你的指示移动。
一块3英尺×5英尺的地毯可以承载最多200磅的重量，并以80英尺的速度飞行。飞毯的载重上限为正常载重的两倍，但超过正常载重时飞毯的飞行速度减半。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:飞毯（3尺×5尺）', name: '飞毯（3尺×5尺）', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:飞毯（3尺×5尺）' }]`（一件物品有好几种次数，就用 '物品次数:飞毯（3尺×5尺）:<短名>'）。

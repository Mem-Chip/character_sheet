# 任务 I183：害兽帽

- 条目键：`XDMG:item:害兽帽`
- 出处：魔法物品（普通）

## 原文

这顶帽子有3充能。持握此帽期间，你可以用一个魔法动作消耗1充能，召唤你选择的下述三种生物之一：一只蝙蝠，一只青蛙或一只老鼠。召唤出的生物魔法性地出现在帽子中，并且会试图尽快远离你。此生物对你和其他生物的态度是冷漠【态度】，且不在你的控制之下。它会如其种类的普通生物一般行动，且会在1小时或者生命值降至0点时消失。此帽在每日黎明时恢复所有已消耗的充能。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:害兽帽`：害兽帽（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:害兽帽', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:害兽帽', name: '害兽帽', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:害兽帽' }]`（一件物品有好几种次数，就用 '物品次数:害兽帽:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

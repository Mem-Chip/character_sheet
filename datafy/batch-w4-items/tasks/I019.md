# 任务 I019：夸力许装置

- 条目键：`XDMG:item:夸力许装置`
- 出处：魔法物品（传说）

## 原文

这件物品最初看起来是一个密封的铁制木桶，重达500磅。木桶有一个隐藏的开关，可以通过成功的DC 20智力（调查）检定发现。释放开关会解锁木桶一端的舱口，允许两个中型或更小的生物爬入内部。远端排列着十个操纵杆，每个都处于中立位置，可以上下移动。当使用特定操纵杆时，该装置会变形为类似一个巨大龙虾的外观。
夸力许装置是一个大型物件，并具有以下数据：AC 20；HP 200；速度 30尺，游泳速度 30尺（若装置腿部未展开则均为0尺）；免疫毒素和心灵伤害。
要将夸力许装置用作载具，需要一个飞行员。当装置的舱门关闭时，舱室是气密且防水的。舱室内的空气足够供10小时的呼吸，由内部呼吸的生物数量均分。
夸力许装置可以浮在水面上。它也可以下潜至900尺深的水下。超过这个深度，载具每分钟会受到来自压力的2d6点钝击伤害。
隔间内的生物可以采取一个操作动作来移动夸力许装置的两个拉杆向上或向下。每次使用后，拉杆会回到绝对中立位置。从左到右的每个拉杆功能如夸力许装置拉杆表格所示。
【夸力许装置拉杆】
| 拉杆 | Up | 下 |
| 1 | 腿部伸展，使装置能够行走和游泳。 | 腿部收缩，将夸力许装置的速度和游泳速度降为0，且无法从速度增益中获益。 |
| 2 | 前窗百叶窗打开。 | 前窗百叶窗关闭。 |
| 3 | 侧窗百叶窗打开（每侧两个）。 | 侧窗百叶窗关闭（每侧两个）。 |
| 4 | 装置前侧伸出两只爪子。 | 爪子收回。 |
| 5 | 每只钳爪发动如下近战攻击：8，触及5尺。命中：：7（2d6）钝击伤害。 | 每只钳爪发动如下近战攻击：8，触及5尺。命中：：目标陷入受擒状态（逃脱DC 15）。 |
| 6 | 夸力许装置在腿部伸展的情况下可以向前行走或游泳。 | 夸力许装置在腿部伸展的情况下可以向后行走或游泳。 |
| 7 | 夸力许装置在腿部伸展的情况下可以逆时针旋转90度。 | 夸力许装置在腿部伸展的情况下可以顺时针旋转90度。 |
| 8 | 眼状装置会发出半径30尺的明亮光照和额外30尺的微光光照。 | 灯光熄灭。 |
| 9 | 夸力许装置在液体中会下沉至多20尺。 | 夸力许装置在液体中可上升至20尺高。 |
| 10 | 后舱门解锁并打开。 | 后舱门关闭并密封。 |

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。

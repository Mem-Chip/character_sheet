# 任务 I077：江湖骗子披风

- 条目键：`XDMG:item:江湖骗子披风`
- 出处：魔法物品（珍稀）

## 原文

这件披风闻起来有一股淡淡的硫磺味。着装该披肩期间，你可以用一个魔法动作施展法术任意门。该属性一经使用，直至次日黎明前都无法再次使用。
以此施展该法术时，你将在消失的原地留下一团烟雾，之后你伴随着一团类似的烟雾出现在目的地。出现在你离开和到达的位置上的烟雾会造成轻度遮蔽，它在下一个你的回合结束时消散。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:江湖骗子披风', name: '江湖骗子披风', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:江湖骗子披风' }]`（一件物品有好几种次数，就用 '物品次数:江湖骗子披风:<短名>'）。

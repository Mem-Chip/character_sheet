# 任务 I451：饰品法杖

- 条目键：`XDMG:item:饰品法杖`
- 出处：魔法物品（普通）

## 原文

持握这根法杖期间，如果你将一个重量不超过1磅的微型物件（例如一块水晶碎片、一颗鸡蛋、一块石子）放于法杖的尖端，这个物件将会在尖端旁1寸的位置漂浮着，直到该物件被移除或法杖不在你手里。这根法杖同一时间至多可以让三个这样的物件在尖端漂浮。持握此法杖期间，你可以让这些物件中的一个或多个缓慢地绕着法杖旋转或原地自转。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:饰品法杖', name: '饰品法杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:饰品法杖' }]`（一件物品有好几种次数，就用 '物品次数:饰品法杖:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

# 任务 I204：不动权杖

- 条目键：`XDMG:item:不动权杖`
- 出处：魔法物品（非普通）

## 原文

这根铁质权杖的一端具有一枚按钮。你可以执行操作动作按下按钮，让这根权杖魔法性地固定在原处。直到你或另一生物执行操作动作再次按下按钮前，即使违反了重力定律，权杖也不会移动。权杖最多能负载8000磅的重量。更重的负载则会让权杖的效应失效并掉落在地。一个生物可以执行操作动作来进行一次DC 30的力量（运动）检定，成功则可以将固定住的权杖移动最多10尺。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:不动权杖', name: '不动权杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:不动权杖' }]`（一件物品有好几种次数，就用 '物品次数:不动权杖:<短名>'）。

## 接口

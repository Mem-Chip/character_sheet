# 任务 I170：幻惑镶钉皮甲

- 条目键：`XDMG:item:幻惑镶钉皮甲`
- 出处：魔法物品（珍稀）

## 原文

穿着这件护甲期间，你的护甲等级获得+1加值。你还可以用一个附赠动作使这件护甲的外观幻化为任何非金属的衣物或其他种类的护甲。幻化后的外观由你决定——包括颜色、样式和配饰——但其体积和重量不变。幻化外观的效应持续到你脱掉此护甲或再次改变护甲外观。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:幻惑镶钉皮甲', name: '幻惑镶钉皮甲', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:幻惑镶钉皮甲' }]`（一件物品有好几种次数，就用 '物品次数:幻惑镶钉皮甲:<短名>'）。

# 任务 I115：黑暗碎片护符

- 条目键：`XDMG:item:黑暗碎片护符`
- 出处：魔法物品（普通，需同调）

## 原文

这个护符由来自异界的弹性材料碎片制成。佩戴此护符期间，你获得以下增益。
【法器】
你可以把护符当作你施展魔契师法术时的法器使用。
【未知法术】
作为一个魔法动作 ，你可以尝试施展一道你未知的戏法。该戏法必须在魔契师法术列表之内且施法时间为1动作。随后你进行一次DC 10的智力（奥秘）检定，检定通过则你施展该法术，检定失败则法术失效，且你施法所用的动作将被浪费。无论发生哪种情况，那之后直至你完成长休前都无法再次使用该词条。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:黑暗碎片护符', name: '黑暗碎片护符', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:黑暗碎片护符' }]`（一件物品有好几种次数，就用 '物品次数:黑暗碎片护符:<短名>'）。

# 任务 I182：万法无常帽

- 条目键：`XDMG:item:万法无常帽`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

这顶尖顶帽具有以下词条：
【法器】
持握这顶帽子期间，你可以将其作为你施展法师法术的法器使用。任何你通过这顶帽子施展的法术均具有特殊的姿势成分，即你必须将手伸入帽子之中以将法术从中"拽"出来。
【未知法术】
持握这顶帽子期间，你可以尝试施展一道你并未已知的一环或以上法术。所选法术必须位于法师法表中，同时其环阶必须是你能够施展的法术环阶，其也不能具有多于1000GP的材料成分。一旦你决定了施展哪道法术，你必须消耗法术环阶所对应的一个法术位。随后，为了决定你是否施展该法术，进行一次智力（奥秘）检定（DC 10+法术环阶）。检定成功，则你以该法术的正常施法时间施展该法术，且你直到完成一次短休或长休之前不能再次使用此词条。检定失败，则你施法失败，转而在下表掷骰以决定触发的随机效应。
你通过帽子施展的所有法术均使用你的法术豁免DC和法术攻击加值。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:万法无常帽', name: '万法无常帽', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:万法无常帽' }]`（一件物品有好几种次数，就用 '物品次数:万法无常帽:<短名>'）。

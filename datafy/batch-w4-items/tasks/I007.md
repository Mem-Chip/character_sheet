# 任务 I007：+3 契约掌控者权杖

- 条目键：`XDMG:item:+3 契约掌控者权杖`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

当持握这根权杖时，你的魔契师法术的法术攻击检定和豁免DC获得+3加值。
此外，持握这根权杖期间，你能够以一个魔法动作恢复一个法术位。该词条一经使用，你在完成一次长休后都无法再次使用。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:+3 契约掌控者权杖', name: '+3 契约掌控者权杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:+3 契约掌控者权杖' }]`（一件物品有好几种次数，就用 '物品次数:+3 契约掌控者权杖:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

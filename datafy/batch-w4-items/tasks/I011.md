# 任务 I011：炽火胶

- 条目键：`XPHB:item:炽火胶`
- 出处：冒险装备

## 原文

当你执行攻击动作时，你可以将你的一次攻击替换为丢出一扁瓶炽火胶。你可以选择位于你20尺内可见的一个生物或物件作为目标。该目标必须通过一次敏捷豁免（DC 8+你的敏捷调整值+你的熟练），否则承受1d4点火焰伤害并开始燃烧。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品:炽火胶`：炽火胶（数量）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:炽火胶' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:炽火胶', name: '炽火胶', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:炽火胶' }]`（一件物品有好几种次数，就用 '物品次数:炽火胶:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

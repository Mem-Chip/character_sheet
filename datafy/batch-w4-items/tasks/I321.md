# 任务 I321：剧毒药水

- 条目键：`XDMG:item:剧毒药水`
- 出处：魔法物品（非普通）

## 原文

这瓶混合物看起来，闻起来和尝起来都和治疗药水或其他增益药水相似。然而，这实际上是一瓶用幻术魔法伪装的毒药。鉴定术可以揭露其本质。
如果你饮下这瓶药水，你受到4d6毒素伤害并必须通过DC 13的体质豁免否则陷入中毒状态，持续1小时。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品:剧毒药水`：剧毒药水（数量）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:剧毒药水' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:剧毒药水', name: '剧毒药水', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:剧毒药水' }]`（一件物品有好几种次数，就用 '物品次数:剧毒药水:<短名>'）。

# 任务 I119：伊格薇尔伏恶魔志

- 条目键：`XDMG:item:伊格薇尔伏恶魔志`
- 出处：魔法物品（神器，需同调）

## 原文

这篇记录着深渊之无限层级及其居民的论文，由伊格薇尔伏撰写，被公认为是多元宇宙中最详细且最亵渎的恶魔学著作。这本书记载了关于深渊与恶魔的所有亵渎事项，无论其有多古远或者多时新。恶魔们曾试图删减过其中的文本，虽部分内容已从书脊上撕下，但大部分篇章仍存，并不断揭示着恶魔的秘密。这本书隐藏着一块神秘的深渊位面碎片，使得此书无论被撕掉多少页，也会时刻保持更新，这本书也不仅仅只是满足于成为一本参考材料。
【深渊学识】
每当你进行智力检定以辨别有关恶魔的信息或进行与深渊相关的感知（求生）检定时，你都可以参考恶魔志。若如此做，你在检定上具有优势。
【封印】
《恶魔之书》的前十页是空白的。当你持有这本书时，你可以作为一个魔法动作，以你能看到且被困在防护法阵法术区域内的一个恶魔为目标。该恶魔必须通过一个DC 20魅力豁免检定，并且由于劣势，若失败则会被困在《恶魔之书》的一页空白页中，该页面上会详细记载该生物广为人知的名字和恶行。一旦使用，该动作直到下一个黎明前无法再次使用。
当你完成一次长休时，如果你与恶魔宝典处于同一存在位面，书中一只被囚禁的生物可以尝试附身于你。你需要进行一次DC 20魅力豁免。若豁免失败，你将被该生物附身，它会像操纵傀儡一样控制你。作为一个魔法动作，附身生物可以释放你并出现在离你最近的未被占据的空间。若豁免成功，该魔鬼在7天内无法再次尝试附身你（但书中其他被囚禁的魔鬼当然可以尝试）。
当这本典籍被发现时，它的页面上通常有1d4个恶魔占据着——通常是各种恶魔的混合。
【迷惑】
当你携带此书时，每当你施放仅以魔鬼为目标的防护法阵或施放以魔鬼为目标的异界誓缚时，该法术将以9环施放，无论你使用了何种法术位（如果有的话）。此外，魔鬼在对抗该法术的豁免检定上具有劣势。
【鞭笞邪魔】
携带这本书时，当你对一个恶魔施放法术并进行伤害骰时，你使用最大可能的结果而不是进行掷骰。
【随机词条】
这件神器具有以下随机属性：
- 2项神器词条; 次要增益词条词条
- 1项神器词条; 次要减益词条词条
- 1项神器词条; 主要减益词条词条
【法术】
这本书有8次充能，每天黎明时分恢复1d8次已消耗的充能。手持此书时，你可以进行一次魔法动作来施放下表中的其中一个法术（通过DC 20检定）。表格显示了施放该法术所需消耗的充能次数。
| 法术 | 消耗充能 |
| 防护法阵 | 1 |
| 魔魂壶 | 3 |
| 异界誓盟 | 3 |
| 异界誓缚 | 2 |
| 位面转移（仅传送至无底深渊） | 3 |
| 邪魔召唤术 | 3 |
| 塔莎狂笑术 | 0 |
【摧毁恶魔志】
要摧毁这本书，必须由六位不同的恶魔领主各自撕下书页的六分之一。若成功执行，这些书页将在24小时后重新出现。在上述时限内打开残留书封者，将被传送至潜藏于书中的无底深渊新生层面。在这致命且半活化的领域中央，藏着失落已久的圣物——弗拉兹厄鲁之杖。若将此杖拖出微型位面，这本典籍就会退化为一本平凡过时的《西克斯典籍》（即《伊格维尔伏恶魔志》的原始底本）。《西克斯典籍》可如同普通书籍般被摧毁。一旦魔杖现世，恶魔领主弗拉兹厄鲁会立即感知。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 8 发充能：花充能写 `cost: [{ resource: '物品充能:伊格薇尔伏恶魔志', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:伊格薇尔伏恶魔志', name: '伊格薇尔伏恶魔志', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:伊格薇尔伏恶魔志' }]`（一件物品有好几种次数，就用 '物品次数:伊格薇尔伏恶魔志:<短名>'）。

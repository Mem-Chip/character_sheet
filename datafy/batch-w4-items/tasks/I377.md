# 任务 I377：公羊戒指

- 条目键：`XDMG:item:公羊戒指`
- 出处：魔法物品（珍稀，需同调）

## 原文

这枚戒指具有3充能，且在每日黎明时重获1d3已消耗的充能。着装此戒指期间，你可以执行魔法动作并消耗1至3充能，对60尺内的一个可见生物进行一次远程法术攻击。戒指创造出一个灵体公羊脑袋并进行具有+7加值的攻击检定。命中时，你每消耗1充能，目标就会受到2d10点力场伤害并且从你的方向被推离5尺。
作为另一种用法，你可以执行魔法动作并消耗1至3充能，以尝试破坏一件60尺内你可见且未被着装或携带的非魔法性的物体。戒指将进行力量检定，你每消耗1充能，此检定便具有+5加值。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:公羊戒指`：公羊戒指（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:公羊戒指', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:公羊戒指', name: '公羊戒指', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:公羊戒指' }]`（一件物品有好几种次数，就用 '物品次数:公羊戒指:<短名>'）。

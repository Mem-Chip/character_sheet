# 任务 I479：触须权杖

- 条目键：`XDMG:item:触须权杖`
- 出处：魔法物品（珍稀，需同调）

## 原文

这根权杖的末端长着三条有弹性的触须。持握这根权杖时，你可以执行魔法动作来指挥触手向外伸展，每一条都会对你可见的15尺之内的一个生物发动攻击。为每条触须进行+9加值的近战攻击检定。单条触须命中时会造成1d6心灵伤害。如果你用三条触须击中同一目标，则该目标必须成功通过DC 15的敏捷豁免，否则将陷入束缚状态。束缚将持续直至你陷入失能状态，花费附赠动作放开目标或目标不再处于你的15尺之内时。当目标被以此法束缚时，在其每个回合开始时都会受到3d6心灵伤害。目标在其每回合结束时可以重新进行这次豁免，豁免成功则终止其身上的效应。

## 可以花的资源（cost 里的 resource 只能用这些 id）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:触须权杖', name: '触须权杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:触须权杖' }]`（一件物品有好几种次数，就用 '物品次数:触须权杖:<短名>'）。

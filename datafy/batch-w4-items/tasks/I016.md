# 任务 I016：位面护符

- 条目键：`XDMG:item:位面护符`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

佩戴此护符期间，你能够以一个魔法动作指名一个位于其他存在位面的你所熟悉的地点。那之后你进行一次DC 15的智力（奥秘）检定。如检定通过，你施展位面转移。如检定失败，你和位于你15尺内的每个生物与物件将被传送至一个由投掷1d100并根据下表决定的随机目的地。
| 1d100 | 目的地 |
| 01-60 | 与你指名地点同一位面的随机地点。 |
| 61-70 | 投掷1d6决定某内层位面中的随机地点：1气之位面；2土之位面；3火之位面；4水之位面；5妖精荒野；6堕影冥界。 |
| 71-80 | 投掷1d8决定某外层位面中的随机地点：1奔放之野；2世外桃源；3万兽乡；4双生天堂；5极乐境；6机械境；7天堂山；8伊斯加德。 |
| 81-90 | 投掷1d8决定某外层位面中的随机地点：1无底深渊；2修罗场；3卡瑟利；4焦炎火狱；5哈迪斯；6混沌海；7九层地狱；8喧癫空隧。 |
| 91-00 | 星界位面中的随机地点。 |

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:位面护符', name: '位面护符', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:位面护符' }]`（一件物品有好几种次数，就用 '物品次数:位面护符:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

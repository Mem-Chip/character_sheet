# 任务 I457：治愈法杖

- 条目键：`XDMG:item:治愈法杖`
- 出处：魔法物品（珍稀，需同调）

## 原文

这根法杖具有10充能。持握这根法杖期间，你可以从法杖中施展以下表格中的一道法术，使用你自己的施法属性调整值。施展相应法术所需消耗的充能数如下表所示。
| 法术 | 消耗充能 |
| 疗伤术 | 每法术等级1次充能（4环法术最多4次充能） |
| 次等复原术 | 2 |
| 群体疗伤术 | 5 |
【重获充能】
这根法杖在每日黎明时恢复1d6 + 4发已消耗的充能。当充能数耗尽时，骰一次1d20。如果骰值为1，法杖将在一阵亮光或闪烁中永久消失。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:治愈法杖`：治愈法杖（充能 10）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 10 发充能：花充能写 `cost: [{ resource: '物品充能:治愈法杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:治愈法杖', name: '治愈法杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:治愈法杖' }]`（一件物品有好几种次数，就用 '物品次数:治愈法杖:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

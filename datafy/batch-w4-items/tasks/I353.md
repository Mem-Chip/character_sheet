# 任务 I353：命令元素戒指（气）

- 条目键：`XDMG:item:命令元素戒指（气）`
- 出处：魔法物品（传说，需同调）

## 原文

命令元素戒指（气）连接着气元素位面。每枚命令元素戒指都具有以下两种词条：
- 【元素灾厄】着装戒指期间，你对元素的攻击检定具有优势，且元素对你的攻击具有劣势。
- 【元素强令】着装戒指期间，你可以执行魔法动作来尝试强迫一个可见的，位于你60尺内的元素服从于你。该元素进行一次DC 18的感知豁免。豁免失败时，该元素直到你的下个回合开始前陷入魅惑状态，且你决定其下一回合他将使用移动和动作做什么。
【元素集中】
着装戒指期间，你受益于与该戒指连接的元素位面对应的额外词条：
- 【气】你懂气族语，你对闪电伤害具有抗性，你获得等于你的速度的飞行速度并且可以悬浮。
【施法】
这枚戒指具有5充能，并在每日黎明时重获1d4 + 1已消耗的充能。着装戒指期间，你可以从中施展法术。施展相应法术所需的充能数如该表所示，法术的豁免DC为18。羽落术（0充能）、风墙术（1充能）、造风术（2充能）、连锁闪电（3充能）

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:命令元素戒指（气）`：命令元素戒指（气）（充能 5）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 5 发充能：花充能写 `cost: [{ resource: '物品充能:命令元素戒指（气）', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:命令元素戒指（气）', name: '命令元素戒指（气）', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:命令元素戒指（气）' }]`（一件物品有好几种次数，就用 '物品次数:命令元素戒指（气）:<短名>'）。

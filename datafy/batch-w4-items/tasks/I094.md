# 任务 I094：隐形斗篷

- 条目键：`XDMG:item:隐形斗篷`
- 出处：魔法物品（传说，需同调）

## 原文

这件斗篷有3点充能，并在每日拂晓时恢复1d3点已消耗的充能。当你穿着这件斗篷时，你可以用一个魔法动作拉起兜帽并消耗1点充能，使你获得隐形状态，持续1小时。如果你拉下兜帽（无需动作）或不再穿着这件斗篷，该效应提前结束。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:隐形斗篷`：隐形斗篷（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:隐形斗篷', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:隐形斗篷', name: '隐形斗篷', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:隐形斗篷' }]`（一件物品有好几种次数，就用 '物品次数:隐形斗篷:<短名>'）。

## 接口

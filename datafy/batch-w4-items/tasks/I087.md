# 任务 I087：开门钟琴

- 条目键：`XDMG:item:开门钟琴`
- 出处：魔法物品（珍稀）

## 原文

这种空心金属管长约1尺，重1磅。你可以用一个魔法动作敲击它以施展法术敲击术。此时，该法术中响亮的敲击声将被钟琴清晰的声音所取代，其声响最远 300 尺内都能听见。开门钟琴可使用 10 次。使用 10 次后，它将碎裂并失去它的能力。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:开门钟琴', name: '开门钟琴', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:开门钟琴' }]`（一件物品有好几种次数，就用 '物品次数:开门钟琴:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

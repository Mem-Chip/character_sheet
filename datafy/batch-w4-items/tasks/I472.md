# 任务 I472：凯斯之剑

- 条目键：`XDMG:item:凯斯之剑`
- 出处：魔法物品（神器，需同调）

## 原文

凯斯是一位侍奉维克那的强大战士，他的忠诚赢得了这把宝剑作为奖赏。随着凯斯力量日渐增长，他的野心也随之膨胀。凯斯的佩剑力劝他推翻维克那，并篡夺维克那的王位。传说维克那殒落自凯斯之手，但反叛的副官也遭到厄运，最后只有凯斯的佩剑流传于世。
【嗜血】
这柄剑渴求鲜血。若此剑在出鞘后的1分钟内其锋刃没有尝到鲜血，其持用者进行一次DC 15的魅力豁免，豁免成功则持用者受到3d6心灵伤害。失败则持用者将被剑控制，如同被法术支配怪物操控。剑渴求鲜血，当剑的需求满足时，法术效应结束。
【魔化武器】
你用此剑进行的攻击检定和伤害掷骰获得+3加值，你用此剑进行的攻击检定在d20中掷出19或20时造成重击，此剑对亡灵额外造成2d10挥砍伤害。
【随机词条】
凯斯之剑具有下列随机词条：
- 1项神器词条; 次要增益词条词条
- 1项神器词条; 主要增益词条词条
- 1项神器词条; 次要减益词条词条
- 1项神器词条; 主要减益词条词条
【法术】
只要此剑在你身上，你就可以从中施展以下法术（豁免DC 18）：
- 召雷术
- 圣言术
- 死亡一指
一旦你使用此剑施展法术，直至次日黎明你都无法再次以此剑施展那个法术。
【凯斯之灵】
只要此剑在你身上，你就获得以下增益：
- 【战斗饥渴】你将1d10加入你的先攻检定。
- 【防御之刃】当你执行动作以此剑发动攻击时，你可以选择将此剑的攻击加值全部或部分转移到你的护甲等级中。加值修改持续至你的下个回合开始。
- 【暗蚀抗性】你获得对暗蚀伤害的抗性。
【智能】
凯斯之剑是一柄混乱邪恶的智能武器，智力为15，感知13，魅力16。它具有120尺听觉及120尺黑暗视觉。
凯斯之剑说通用语并可以通过心灵感应与持用者交流。
【个性】
这柄剑的目标是毁灭维克纳。杀死维克纳的信徒、摧毁巫妖的作品、挫败他的阴谋都有助于实现该目标。
凯斯之剑还试图摧毁任何被维克那法眼和魔掌腐化之人。
【摧毁此剑】
一名同时与维克那法眼和维克那魔掌维持同调的生物，可以使用其祈愿词条摧毁凯斯之剑，此时凯斯之剑需位于施法者30尺内。施展此次祈愿术时，该生物需要进行一次DC 18的魅力豁免，失败则无事发生，祈愿术被浪费；成功则凯斯之剑被摧毁。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:凯斯之剑', name: '凯斯之剑', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:凯斯之剑' }]`（一件物品有好几种次数，就用 '物品次数:凯斯之剑:<短名>'）。

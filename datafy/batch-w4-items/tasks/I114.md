# 任务 I114：淬毒匕首

- 条目键：`XDMG:item:淬毒匕首`
- 出处：魔法物品（珍稀）

## 原文

你以此魔法武器进行的攻击检定和伤害掷骰获得+1加值。
你可以用附赠动作为匕首覆上毒液，持续1分钟。用这把武器发动的一次攻击成功命中生物后毒液也会消失。此时，被命中的生物必须成功通过一次DC 15的体质豁免否则受到2d10毒素伤害并陷入中毒状态1分钟。直至次日黎明前，该附赠动作都无法被再次使用。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:淬毒匕首', name: '淬毒匕首', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:淬毒匕首' }]`（一件物品有好几种次数，就用 '物品次数:淬毒匕首:<短名>'）。

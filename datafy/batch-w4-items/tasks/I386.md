# 任务 I386：虹光法袍

- 条目键：`XDMG:item:虹光法袍`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

这件长袍具有3充能，并每日黎明时重获1d3已消耗的充能。着装这件长袍期间，你可以使用一个魔法动作并消耗1充能，让长袍不断变幻出各种耀眼的色彩图案，持续至你的下个回合结束。在此期间，长袍提供30尺明亮光照和额外30尺微光光照，能看到你的生物对你发动的攻击检定具有劣势。此外，长袍效应启用期间，任何处于长袍产生的明亮光照区域内且可以看到你的生物必须进行一次DC 15的感知豁免，豁免失败则陷入震慑状态，直到长袍的效应终止。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:虹光法袍`：虹光法袍（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:虹光法袍', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:虹光法袍', name: '虹光法袍', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:虹光法袍' }]`（一件物品有好几种次数，就用 '物品次数:虹光法袍:<短名>'）。

## 接口

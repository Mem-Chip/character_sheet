# 任务 I149：无尽烟壶

- 条目键：`XDMG:item:无尽烟壶`
- 出处：魔法物品（非普通）

## 原文

以一个魔法动作，你可以开关这个瓶子。
打开此瓶会使浓重的烟雾从中涌出，形成一团浓厚的烟云。烟云会充满以此瓶为源点的60尺光环 [效应区域]。被烟云笼罩的区域处于重度遮蔽。
只要瓶子保持开启，每1分钟此光环 [效应区域]就会扩大10尺，最大达到120尺。
关闭此瓶会使烟云固定在原地，直至10分钟后消散。一阵强风（例如造风术所创造的）可以在1分钟后将其吹散。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:无尽烟壶', name: '无尽烟壶', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:无尽烟壶' }]`（一件物品有好几种次数，就用 '物品次数:无尽烟壶:<短名>'）。

# 任务 I488：唤鱼三叉戟

- 条目键：`XDMG:item:唤鱼三叉戟`
- 出处：魔法物品（非普通，需同调）

## 原文

这把魔法武器具有3充能，并在每日黎明时重获1d3已消耗的充能。当你携带这把武器时，你可以消耗1充能对一只具有游泳速度的野兽施展支配野兽（豁免DC 15）。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:唤鱼三叉戟`：唤鱼三叉戟（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:唤鱼三叉戟', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:唤鱼三叉戟', name: '唤鱼三叉戟', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:唤鱼三叉戟' }]`（一件物品有好几种次数，就用 '物品次数:唤鱼三叉戟:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

# 任务 I208：撰写乐器

- 条目键：`XDMG:item:撰写乐器`
- 出处：魔法物品（普通）

## 原文

这把乐器具有3充能，并在每日黎明时重获所有已消耗的充能。在你使用这把乐器进行演奏期间，你可以使用一个魔法动作消耗1充能，在你周边30尺范围内一个可见的非魔法物件或表面上写下一段魔法信息。这段信息以一种你熟知的语言书写，且其最长六个单词。如果你是一名吟游诗人，则你可写的单词上限增加七个，并且你可以使信息发出微弱光芒，使其在非魔法黑暗中清晰可见。信息会在24小时后消失，也可用法术解除魔法将其抹去。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:撰写乐器`：撰写乐器（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:撰写乐器', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:撰写乐器', name: '撰写乐器', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:撰写乐器' }]`（一件物品有好几种次数，就用 '物品次数:撰写乐器:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

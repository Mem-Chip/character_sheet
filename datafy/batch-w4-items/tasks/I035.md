# 任务 I035：力场珠

- 条目键：`XDMG:item:力场珠`
- 出处：魔法物品（珍稀）

## 原文

这个小型黑色球体直径3/4寸，重1/2盎司。被发现时通常都会有1d4 + 4颗珠子放在一起。
你能够以一个魔法动作把珠子扔出至多60尺远。珠子在落点处引发爆炸并因此被摧毁，其周围半径10尺球状 [效应区域]内每个生物必须进行一次DC 15的敏捷豁免，豁免失败者受到5d4点力场伤害。此外，球型的隐形力场将封闭该球状 [效应区域]1分钟。任何豁免失败且完全处于范围中的生物会被困在里面。豁免成功或部分处于范围中的生物会沿着远离球型中心的方向被推出范围。攻击或其他效应无法进入球型力场，但供呼吸的空气可以顺利流通。
被困在内部的生物能够以一个操作动作推动力场障壁，移动至多相当于该生物速度一半的距离。这个球型障壁也可以被拿起。无论内部的生物有多重，力场珠整体的重量都只有1磅。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品:力场珠`：力场珠（数量）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:力场珠' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:力场珠', name: '力场珠', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:力场珠' }]`（一件物品有好几种次数，就用 '物品次数:力场珠:<短名>'）。

# 任务 I438：法术卷轴（一环）

- 条目键：`XDMG:item:法术卷轴（一环）`
- 出处：魔法物品（普通）

## 原文

每张法术卷轴都以神秘暗语记录了一道法术。如果这道法术在你的法术列表中，则你可以阅读该卷轴并施展其法术且无需任何材料成分；否则，你将无法理解该卷轴。通过阅读卷轴施展的法术同样需要遵循相应法术的正常施法时间。法术一经施展，卷轴本身就会化作尘土。如果施法被打断，则卷轴不会消失。
如果这道法术在你的法术列表中，但其环阶高于你当前能施展的水平，则你必须使用你的施法属性进行一次DC 11的属性检定，以决定是否可以施展这道法术。如果检定失败，则卷轴上记载的法术会消失，并且不会产生任何效果。
如果法术需要进行豁免检定或攻击检定，法术豁免DC为13，攻击加值为5。
【将卷轴抄录入法术书】
法师法术卷轴上的法术可以被抄写到法术书中。当以这种方式抄写一个1环法术时，抄写者必须通过一个DC 11智力（奥秘）的检定。如果检定成功，法术被抄写下来。无论检定成功与否，这个法术卷轴都会被销毁。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:法术卷轴（一环）' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:法术卷轴（一环）', name: '法术卷轴（一环）', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:法术卷轴（一环）' }]`（一件物品有好几种次数，就用 '物品次数:法术卷轴（一环）:<短名>'）。

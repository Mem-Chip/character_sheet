# 任务 I130：火巨灵囚瓶

- 条目键：`XDMG:item:火巨灵囚瓶`
- 出处：魔法物品（非常珍稀）

## 原文

当你以一个魔法动作打开这个彩绘的黄铜瓶子的瓶塞时，一团浓烟将从瓶内溢出。在你的回合结束时，烟雾会伴随着一阵无害的火焰而消失，同时一名火巨灵将出现在你周边30尺内一处未被占据的空间。
瓶子第一次被打开时，DM按下面的表格掷骰，以此来决定会发生什么。
| 1d10 | 效应 |
| 1 | 火巨灵攻击你。战斗进行5轮后，火巨灵将消失，同时瓶子将失去魔力。 |
| 2-9 | 在接下来的1小时内，火巨灵理解你的语言并遵循你的命令。在这之后它会重新回到瓶中，而一个新的瓶塞将显现并再次将其封印，且新瓶塞在24小时内都无法被拔出。下两次打开瓶子时会产生同样的效应。当瓶子第四次被打开时，火巨灵将逃走并消失，同时瓶子将失去魔力。 |
| 10 | 火巨灵理解你的语言并能为你施展一次祈愿术。它将在1小时后或施放完祈愿术时消失，同时瓶子将失去魔力。 |

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:火巨灵囚瓶', name: '火巨灵囚瓶', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:火巨灵囚瓶' }]`（一件物品有好几种次数，就用 '物品次数:火巨灵囚瓶:<短名>'）。

# 任务 I261：摄心镜

- 条目键：`XDMG:item:摄心镜`
- 出处：魔法物品（非常珍稀）

## 原文

当以间接的方式看向这面4尺高，2尺宽的镜子时，其表面会显示出生物的模糊影像。这面镜子重50磅，AC11，HP10，免疫毒素和心灵伤害，对钝击伤害具有易伤。当生命值降至0时，镜子会粉碎且被摧毁。
如果镜子悬挂于一处垂直表面，且你在镜子周边5尺范围内时，你可以执行一个魔法动作并使用一个命令语激活它。它会一直保持激活状态，直至你执行一个魔法动作并重复命令语来取消激活。
如果除你之外的任何生物在镜子周边30尺范围内看到自己在已激活镜面中的倒影，该生物必须成功通过一次DC 15的魅力豁免，否则将会连同自己着装或携带的所有物品一起被困入镜中的十二个异次元牢房之一。了解摄心镜本质的生物在进行该豁免时具有优势，构装生物在进行该豁免时直接成功。
每个异次元牢房都是一处无限广阔的空间，里面充满了浓雾，能见度只有10尺。被困入镜中牢房的生物不会衰老，也无需饮食和睡眠。被困于牢房的生物可以使用位面旅行魔法进行逃脱，无法做到这件事的生物将被永远囚禁在牢房中，直至被释放为止。
如果镜子困住一个生物，而十二个异次元牢房又已被占满，则它将随机释放一名被困生物以容纳新囚犯。一个被释放的生物会背对镜子出现在镜子视野范围内一处未被占据的空间中。如果镜子被打碎，它囚禁的所有生物都会被释放，并出现在它附近未被占据的空间里。
位于镜子周边5尺范围内时，你可以使用一个魔法动作说出一位被囚禁生物的名字或呼喊一个特定牢房的编号。被说出名字或被囚禁于该编号牢房的生物会以一幅影像的形式出现在镜子表面，随后你可与该生物进行交流。
以类似的方式，你可以执行一个魔法动作并使用另一个命令语释放一位被困于镜中的生物。被释放的生物会连同其所有物出现离镜子最近的未被占据的空间里，背对着镜子。
将摄心镜放入次元袋、掩护或其他类似物品产生的异次元空间时，将立即摧毁这两件物品并打开一扇通往星光位面的门扉。门扉会产生在被放入另一件物品的前一件物品所在的空间位置。任何在门扉周边10尺范围内且不在全身掩护之后的生物将被吸入门内并送到星光位面的随机位置，随后该门关闭。这扇门扉只能单向通过且无法被再次打开。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:摄心镜', name: '摄心镜', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:摄心镜' }]`（一件物品有好几种次数，就用 '物品次数:摄心镜:<短名>'）。

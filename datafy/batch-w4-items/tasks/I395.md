# 任务 I395：庇护权杖

- 条目键：`XDMG:item:庇护权杖`
- 出处：魔法物品（非常珍稀）

## 原文

当持握这根权杖时，你可以执行魔法动作来激活它。权杖会立刻将你和你可见的至多199名自愿生物传送入一个半位面。你选择半位面所呈现的形式。它可以是宁静的花园、热闹的酒馆、宏伟的宫殿、热带岛屿、梦幻般的嘉年华，或者任何你能想象的场景。无论性质如何，这个半位面有足够的食物和水供访客享用，并且半位面的任何环境都无法伤害到其中的居住者们。此处一切可交互的事物都只能存在于该半位面中。例如，把半位面中花园里摘的花带出半位面时，该花将消失。
在半位面里每度过一个小时，访客们都能如同花费了1个生命值骰一般地恢复生命值。并且尽管半位面中时间将正常流动，但其中的生物不会变老。访客们可以在此停留最多200除以生物数量的天数（向下取整）。
当停留时间耗尽或你执行魔法动作以结束该效应时，所有访客都会重新出现在权杖激活前的位置或该位置最近的未占据的空间里。该词条被使用后，直至过去10天时间才能再次使用。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:庇护权杖', name: '庇护权杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:庇护权杖' }]`（一件物品有好几种次数，就用 '物品次数:庇护权杖:<短名>'）。

# 任务 I385：百眼法袍

- 条目键：`XDMG:item:百眼法袍`
- 出处：魔法物品（珍稀，需同调）

## 原文

这件长袍上绘满了眼睛的图案。着装这件长袍期间，你获得以下增益：
- 【全域视野】你在依赖视觉的感知（察觉）检定中具有优势。
- 【特殊感官】你具有120尺的黑暗视觉和真实视觉。
【缺点】
对法袍施展光亮术或在其周围5尺内施展昼明术将使你陷入目盲，持续1分钟。在你的每个回合结束时，你可以进行一次体质豁免（对光亮术时DC 11，对昼明术时DC 15），成功则终止你身上的该效应。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:百眼法袍', name: '百眼法袍', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:百眼法袍' }]`（一件物品有好几种次数，就用 '物品次数:百眼法袍:<短名>'）。

# 任务 I028：魔术袋，灰色

- 条目键：`XDMG:item:魔术袋，灰色`
- 出处：魔法物品（非普通）

## 原文

这种布袋由灰色布料制成。布袋看起来空无一物，但把手伸进去会摸到一个小小的毛绒物件。
你能够以一个魔法动作取出布袋里的毛绒物件，并把它扔出至多20尺远。当物件落地时，投骰子参考对应颜色布袋的表格决定物件变成的生物。相关生物的资料见怪物图鉴。该生物在次日黎明时分或者其生命值降至0时消失。
扔出的生物对你和你的盟友态度友好【态度】，且会在你的先攻序位后行动。你能够以一个附赠动作命令该生物在其下一回合执行特定的移动方式，做特定的动作，例如攻击你的敌人。没接到命令时，该生物按自己天性行动。
一旦袋子抽出三件毛绒物件后，直至次日黎明才可再次使用。
| 1d8 | 生物 |
| 1 | 鼬 |
| 2 | 巨鼠 |
| 3 | 獾 |
| 4 | 野猪 |
| 5 | 豹 |
| 6 | 巨獾 |
| 7 | 恐狼 |
| 8 | 巨赤鹿 |

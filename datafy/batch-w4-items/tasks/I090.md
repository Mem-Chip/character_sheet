# 任务 I090：节肢斗篷

- 条目键：`XDMG:item:节肢斗篷`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

这件精美的服饰由黑色丝绸制成，其中交织着隐约可见的银色丝线。着装此斗篷期间，你获得以下增益：
【毒素抗性】
你获得对毒素伤害的抗性。
【蛛行术】
你获得与速度相等的攀爬速度，能够在垂直表面上下或横向移动，甚至可以在天花板上倒挂着移动而不需要用到双手。
【蛛网行走】
你不会被任何种类的蛛网困住，在移动穿过蛛网时你将其视为等同于困难地形。
【蛛网术】
你可以施展蛛网术（DC 13）。该法术创造的蛛网将覆盖普通蛛网术正常区域的两倍。该词条一经使用，直至次日黎明前都无法再次使用。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。

- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:节肢斗篷', name: '节肢斗篷', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:节肢斗篷' }]`（一件物品有好几种次数，就用 '物品次数:节肢斗篷:<短名>'）。

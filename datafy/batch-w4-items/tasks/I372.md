# 任务 I372：流星戒指

- 条目键：`XDMG:item:流星戒指`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

你可以从戒指中施展舞光术或光亮术。
这枚戒指具有6充能，并在每日黎明时重获1d6已消耗的充能。你可以消耗充能以使用以下词条。
【妖火】
你可以消耗1充能以从戒指中施展妖火 。
【球状闪电】
你可以消耗2充能，以一个魔法动作创造至多四个3尺直径的闪电球体。
每个球体都出现于120尺内你可见的未占据空间中。只要你为它们维持专注，球体就能持续存在至多1分钟。每个球体都会散发出半径30尺的微光光照。
以一个附赠动作，你可以移动每个球体至多30尺，但球体和你的距离不得超过120尺。球体初次进入一个除你以外的，未处于掩护后的生物5尺内时，球体对那个生物放出闪电并消失。该生物进行一次DC 15的敏捷豁免。豁免失败时，生物受到基于你创造出的球体数量的闪电伤害，如下表所示。豁免成功时，生物受到的伤害减半。
| 球体数量 | 闪电伤害 |
| 1 | 4d12 |
| 2 | 5d4 |
| 3 | 2d6 |
| 4 | 2d4 |
【流星】
以一个魔法动作 ，你可以消耗1至3充能。每一发你消耗的充能都会变为一粒发光尘埃，从戒指处向着你60尺内的一点发射。以该点为源点，15尺立方 [效应区域]内的所有生物将沐浴在火花之中，并进行一次DC 15的敏捷豁免，失败则受到5d4点光耀伤害，成功则伤害减半。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:流星戒指`：流星戒指（充能 6）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 6 发充能：花充能写 `cost: [{ resource: '物品充能:流星戒指', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:流星戒指', name: '流星戒指', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:流星戒指' }]`（一件物品有好几种次数，就用 '物品次数:流星戒指:<短名>'）。

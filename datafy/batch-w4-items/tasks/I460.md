# 任务 I460：虫群法杖

- 条目键：`XDMG:item:虫群法杖`
- 出处：魔法物品（珍稀，需同调）

## 原文

这根法杖具有10充能。
【虫云】
当你持握此法杖时，你可以执行一个魔法动作并消耗1发充能，以召唤一团无害飞虫群，充满一个以你为源点的30尺光环 [效应区域]。虫群持续10分钟，使该区域对你以外的生物处于重度遮蔽状态。一阵强风（例如由造风术创造的）可以驱散虫群并结束该效应。
【法术】
持握这根法杖期间，你可以从法杖中施展以下表格中的一道法术，使用你自己的法术豁免DC。施展相应法术所需消耗的充能数如下表所示。
| 法术 | 消耗充能 |
| 巨虫术 | 4 |
| 疫病虫群 | 5 |
【重获充能】
这根法杖在每日黎明时恢复1d6 + 4发已消耗的充能。当充能数耗尽时，骰一次1d20。如果骰值为1，虫群将蚕食法杖，并在将其摧毁后消散。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:虫群法杖`：虫群法杖（充能 10）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 10 发充能：花充能写 `cost: [{ resource: '物品充能:虫群法杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:虫群法杖', name: '虫群法杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:虫群法杖' }]`（一件物品有好几种次数，就用 '物品次数:虫群法杖:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

# 任务 I120：次元镣铐

- 条目键：`XDMG:item:次元镣铐`
- 出处：魔法物品（珍稀）

## 原文

你可以用操作动作将此镣铐戴在一个失能的生物身上。镣铐可以自行调整适应从小型到大型体型的生物。次元镣铐能够阻止被其约束的生物进行异次元移动，包括传送和异位面旅行。不过镣铐并不能阻止生物穿过一道连接异位面的传送门。
你和你使用镣铐时指定的生物可以用操作动作直接解除此镣铐。每隔30日，被约束的生物可以进行一次DC 30的力量（运动）检定，成功则破坏镣铐重获自由。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:次元镣铐', name: '次元镣铐', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:次元镣铐' }]`（一件物品有好几种次数，就用 '物品次数:次元镣铐:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

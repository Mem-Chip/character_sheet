# 任务 I287：唤鼠乐笙

- 条目键：`XDMG:item:唤鼠乐笙`
- 出处：魔法物品（非普通，需同调）

## 原文

在你随身携带这只乐笙期间，老鼠和巨鼠对你的态度为冷漠【态度】。除非你威胁或伤害它们，否则它们不会主动攻击你。
唤鼠乐笙具有3充能，并在每日黎明时重获1d3已消耗的充能。你可以使用一个魔法动作演奏该乐笙，并使用一个附赠动作消耗1~3充能。如果你周围半里内有足够可供召唤的老鼠（由DM决定），那么每消耗1充能就能召唤1组鼠群。如果范围内鼠的数量不足以形成集群，则该次充能被浪费。被召唤的集群会沿着最短的可用路线向音乐移动，但除此之外不受你的控制。
在你使用魔法动作演奏乐笙期间，每当一个未被其他生物控制的鼠群进入到你周边30尺范围内时，该鼠群就必须进行一次DC 15的感知豁免。如果豁免成功，该鼠群就会像平常一样行动，并在接下来的24小时内不再受到乐笙音乐的影响。如果豁免失败，鼠群就会受到乐笙音乐的影响，并且只要你每轮继续使用一个魔法动作演奏乐笙，鼠群就会对你和你的盟友保持友好【态度】。一个友好【态度】的鼠群会遵从你的命令。当你没对一个友好【态度】的鼠群下达命令时，它们会尽力保护自己，但不会执行其他动作。如果一个友好【态度】的鼠群在距离你30尺以外的地方开始其回合，则你对该鼠群的控制就会终止，鼠群会像平常一样行动，并在接下来的24小时内不再受到乐笙音乐的影响。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:唤鼠乐笙`：唤鼠乐笙（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:唤鼠乐笙', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:唤鼠乐笙', name: '唤鼠乐笙', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:唤鼠乐笙' }]`（一件物品有好几种次数，就用 '物品次数:唤鼠乐笙:<短名>'）。

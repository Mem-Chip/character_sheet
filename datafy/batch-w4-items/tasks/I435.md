# 任务 I435：蛛行便鞋

- 条目键：`XDMG:item:蛛行便鞋`
- 出处：魔法物品（非普通，需同调）

## 原文

着装这双便鞋期间，你无需借助双手即可上下移动，以及穿过垂直表面和沿着天花板移动。你获得等同于你速度的攀爬速度。不过，你无法以此法在滑溜的表面上移动，例如被冰或油覆盖的表面。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:蛛行便鞋', name: '蛛行便鞋', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:蛛行便鞋' }]`（一件物品有好几种次数，就用 '物品次数:蛛行便鞋:<短名>'）。

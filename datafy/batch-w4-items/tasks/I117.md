# 任务 I117：幻象牌组

- 条目键：`XDMG:item:幻象牌组`
- 出处：魔法物品（非普通）

## 原文

这个匣子里装着一套卡牌。一套完整的牌组有34张卡牌：32张描绘着特定的生物，2张则是镜面牌。作为宝藏找到的牌组通常会缺失1d20 - 1张卡牌。
牌组的魔法只有在随机抽出时才会生效。你可以用一个魔法动作从牌组中随机抽出一张卡牌，并将其扔到距离你30尺范围以内的一处地面上。某一生物（根据"幻象牌组表格"掷骰来确定）的幻象会从被扔出的卡牌中显现，并将持续存在直至被解除。由卡牌创造出的幻象生物看起来活灵活现，和真实生物行为相仿，但无法造成伤害。如果你在幻象生物周围120尺范围内且你能看到它，你就可以用一个魔法动作令其移动到卡牌周围30尺内的任何地方。
由于物件可以穿透幻象，因此与幻象生物进行的任何物理互动都将揭示其幻象本质。任一生物都可以用一个研究动作来对幻象生物进行视觉性的观察，此时其成功通过一次DC 15的智力（调查）检定即可发现幻象的本质。幻象将持续存在，直至被解除（使用解除魔法或类似的效应）或其卡牌被移动。当幻象终止时，其卡牌上的图像也随之消失，该卡牌也无法再次使用。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。

- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:幻象牌组', name: '幻象牌组', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:幻象牌组' }]`（一件物品有好几种次数，就用 '物品次数:幻象牌组:<短名>'）。

# 任务 I350：影响动物戒指

- 条目键：`XDMG:item:影响动物戒指`
- 出处：魔法物品（珍稀）

## 原文

这枚戒指具有3充能，并在每日黎明时重获1d3已消耗的充能。着装此戒指期间，你可以消耗1充能，从中施展以下法术之一（豁免DC 13）：
- 化兽为友
- 恐惧术（只影响野兽）
- 动物交谈

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:影响动物戒指`：影响动物戒指（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:影响动物戒指', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:影响动物戒指', name: '影响动物戒指', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:影响动物戒指' }]`（一件物品有好几种次数，就用 '物品次数:影响动物戒指:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

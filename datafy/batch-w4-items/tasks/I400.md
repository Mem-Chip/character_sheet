# 任务 I400：战法红石

- 条目键：`XDMG:item:战法红石`
- 出处：魔法物品（普通，需同调）

## 原文

这枚直径1寸的红宝石上蚀刻着魔能符文。此红宝石允许你使用一把简易或军用武器作为你施展法术的法器。要使该词条生效，你必须将红宝石按压在该武器上至少10分钟，以此将其附着在武器上。随后，除非你使用一个魔法动作将其取下、武器被摧毁或你与红宝石的同调结束，否则红宝石将无法被移除。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:战法红石', name: '战法红石', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:战法红石' }]`（一件物品有好几种次数，就用 '物品次数:战法红石:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

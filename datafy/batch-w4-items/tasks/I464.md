# 任务 I464：丛林法杖

- 条目键：`XDMG:item:丛林法杖`
- 出处：魔法物品（珍稀，需同调）

## 原文

这根法杖具有6充能并可被用作一根魔法长棍（用这根长棍发动的攻击检定和伤害掷骰获得+2加值）。持握此法杖期间，你在法术攻击检定上获得+2加值。
【法术】
持握此法杖期间，你可以从法杖中施展以下表格中的一道法术，使用你自己的法术豁免DC。施展相应法术所需消耗的充能数如下表所示。
| 法术 | 消耗充能 |
| 化兽为友 | 1 |
| 启蒙术 | 5 |
| 树肤术 | 2 |
| 动植物定位术 | 2 |
| 行动无踪 | 2 |
| 动物交谈 | 1 |
| 植物交谈 | 3 |
| 棘墙术 | 6 |
【树木型态】
你可以执行魔法动作来将法杖的一端插入一处未占据空间的土地上，并消耗1充能将其转变为一颗健壮的树。这棵树高60尺，树干直径5尺，顶端的树冠以20尺半径向外延伸。这棵树外观与普通的树无异，但侦测魔法能辨别出树上散发出的微弱变化系魔法灵光。你可以在触碰这棵树时执行魔法动作 将其变回原本的法杖形态。当树还原回法杖时，任何在树上的生物都会掉下来。
【重获充能】
这根法杖在每日黎明时重获1d6已消耗的充能。当充能数耗尽时，骰一次1d20。如果骰值为1，法杖失去其所有词条并将变为一根非魔法性的长棍。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:丛林法杖`：丛林法杖（充能 6）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 6 发充能：花充能写 `cost: [{ resource: '物品充能:丛林法杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:丛林法杖', name: '丛林法杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:丛林法杖' }]`（一件物品有好几种次数，就用 '物品次数:丛林法杖:<短名>'）。

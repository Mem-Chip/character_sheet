# 任务 I153：微视镜片

- 条目键：`XDMG:item:微视镜片`
- 出处：魔法物品（非普通）

## 原文

这副水晶镜片适合戴在眼前。佩戴着这副镜片期间，你观察周边1尺距离内的事物时的视力显著提高，这将给予你此范围内的黑暗视觉，并使你为检视某物而进行的智力（调查）检定具有优势。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:微视镜片', name: '微视镜片', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:微视镜片' }]`（一件物品有好几种次数，就用 '物品次数:微视镜片:<短名>'）。

# 任务 I026：吞噬袋

- 条目键：`XDMG:item:吞噬袋`
- 出处：魔法物品（非常珍稀）

## 原文

这个类似于次元袋的袋子实际上是某个巨大异次元生物的进食口。将袋子内外翻转就可以关闭进食口的通道。
与这个袋子关联的异次元生物可以感知到任何放入袋中的东西。完整放入袋中的动物或植物将被吞噬而永久消失。活物的一部分被放入袋中时（例如有人把手伸入袋子里时），该生物有50%概率被拖入袋中。进入袋中的生物能够以一个动作进行一次DC 15的力量（运动）检定以从中逃脱。另一个生物能够以一个动作 进行一次DC 20的力量（运动）检定来将被吞噬的生物拉出来，前提是该生物自己没被拖入袋中。任何在袋中开始其自己回合的生物都将被吞噬，其躯体被摧毁。
无生命物件可以存放在袋子里，袋子至多可容纳1立方尺的东西。此外，该袋子每日会有一次将其内的所有物件吐到另一存在位面。具体哪个位面由DM决定。
袋子被戳破或撕裂时即被摧毁。其内的所有东西都将被传送到星界位面的随机地点。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:吞噬袋', name: '吞噬袋', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:吞噬袋' }]`（一件物品有好几种次数，就用 '物品次数:吞噬袋:<短名>'）。

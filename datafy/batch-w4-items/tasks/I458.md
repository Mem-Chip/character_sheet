# 任务 I458：威力法杖

- 条目键：`XDMG:item:威力法杖`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

这根法杖具有20充能并可被用作一根魔法长棍（用这根长棍发动的攻击检定和伤害掷骰获得+2加值）。持握此法杖期间，你在护甲等级、豁免和法术攻击检定上获得+2加值。
【法术】
持握此法杖期间，你可以从法杖中施展以下表格中的一道法术，使用你自己的法术豁免DC。施展相应法术所需消耗的充能数如下表所示。
| 法术 | 消耗充能 |
| 寒冰锥 | 5 |
| 火球术（五环版本） | 5 |
| 法术无效结界 | 6 |
| 定身怪物 | 5 |
| 浮空术 | 2 |
| 闪电束（五环版本） | 5 |
| 魔法飞弹 | 1 |
| 衰弱射线 | 1 |
| 力场墙 | 5 |
【重获充能】
这根法杖在每日黎明时重获2d8 + 4已消耗的充能。当充能数耗尽时，骰一次1d20。如果骰值为1，法杖将失去除了攻击检定与伤害掷骰获得+2加值以外的其他所有词条。如果骰值为20，法杖恢复1d8 + 2充能。
【复仇打击】
你可以执行魔法动作，在自己的膝盖或坚硬的表面上将法杖折断。法杖将被摧毁，释放出所有魔力，并在以其为源点的30尺光环 [效应区域]范围内发出爆炸。你有50%的概率被传送到某个随机的存在位面以避开爆炸。如果你没能避开爆炸效应，你将受到16×法杖剩余充能数点力场伤害。区域中的所有其他生物必须进行一次DC 17的敏捷豁免。豁免失败则其受到4×法杖剩余充能数点力场伤害，豁免成功则伤害减半。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:威力法杖`：威力法杖（充能 20）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 20 发充能：花充能写 `cost: [{ resource: '物品充能:威力法杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:威力法杖', name: '威力法杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:威力法杖' }]`（一件物品有好几种次数，就用 '物品次数:威力法杖:<短名>'）。

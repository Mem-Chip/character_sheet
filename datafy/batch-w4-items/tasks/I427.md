# 任务 I427：短讯石

- 条目键：`XDMG:item:短讯石`
- 出处：魔法物品（非普通）

## 原文

短讯石两颗一对，这两块石头经过雕刻而相互匹配，因此它们的配对非常容易辨认。触摸其中一块短讯石期间，你可以用它施展短讯术，目标为另一块短讯石的携带者。如果另一块短讯石没有被任何生物携带，则你在使用短讯石时会得知这一情况，而短讯术将不会被施展。
一旦使用其中一块短讯石施展了短讯术，则两块短讯石直至次日黎明前都无法再次被使用。如果一块短讯石被摧毁，则与它配对的另一块石头也会失去其魔法。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:短讯石', name: '短讯石', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:短讯石' }]`（一件物品有好几种次数，就用 '物品次数:短讯石:<短名>'）。

# 任务 I111：召唤魔方

- 条目键：`XDMG:item:召唤魔方`
- 出处：魔法物品（珍稀）

## 原文

这个小立方体如同一个玩偶盒。当你用一个魔法动作转动立方体的曲柄时，它的盖子将在欢快的曲调中弹开，一个生物出现在距离盒子最近的未被占据的空间，而后盖子再次关闭。该盖子无法被其他手段打开。
在召唤魔方表中掷骰以确定召唤魔方施展了哪种法术以召唤生物。该法术以五环法术位施展（豁免DC 17，攻击加值+9）且无需维持专注，但你在其他方面视为该法术的施法者。
一旦该立方体召唤了一个生物，直至次日黎明前它都无法再次召唤生物。
【召唤魔方】
| 1d6 | 法术 |
| 1 | 异怪召唤术 |
| 2 | 野兽召唤术 |
| 3 | 构装召唤术 |
| 4 | 龙类召唤术 |
| 5 | 元素召唤术 |
| 6 | 妖精召唤术 |

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:召唤魔方', name: '召唤魔方', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:召唤魔方' }]`（一件物品有好几种次数，就用 '物品次数:召唤魔方:<短名>'）。

# 任务 I461：蝰蛇法杖

- 条目键：`XDMG:item:蝰蛇法杖`
- 出处：魔法物品（非普通，需同调）

## 原文

以一个附赠动作，你可以将法杖的头部变为一条会动的毒蛇，持续一分钟，或直至你执行附赠动作将法杖还原为非活化形态。
当你执行攻击动作时，你可以使用触及5尺的活化蛇头来发动其中一次攻击检定。这次攻击检定使用你的熟练与感知调整值。命中时，目标将受到1d6穿刺伤害与3d6毒素伤害。
蛇头在活化期间可以被攻击。它具有AC15，HP20，免疫毒素与心灵伤害。蛇头的生命值降为0时法杖将被摧毁。只要法杖未被摧毁，它就会在还原为非活化形态时恢复所有失去的生命值。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:蝰蛇法杖', name: '蝰蛇法杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:蝰蛇法杖' }]`（一件物品有好几种次数，就用 '物品次数:蝰蛇法杖:<短名>'）。

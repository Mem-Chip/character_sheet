# 任务 I036：营养珠

- 条目键：`XDMG:item:营养珠`
- 出处：魔法物品（普通）

## 原文

这个没有味道的凝胶珠子在你的舌头上溶解时，它会为你提供等同于一天份口粮的营养。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品:营养珠`：营养珠（数量）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:营养珠' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:营养珠', name: '营养珠', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:营养珠' }]`（一件物品有好几种次数，就用 '物品次数:营养珠:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

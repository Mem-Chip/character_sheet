# 任务 I158：异能塑像，象牙山羊

- 条目键：`XDMG:item:异能塑像，象牙山羊`
- 出处：魔法物品（珍稀）

## 原文

异能塑像是小到可以装在口袋里的小雕塑。当你用一个魔法动作来将雕像扔到你周围60尺以内的某处时，它将变成一只活体生物（见下文对每种雕像的描述）。如果雕像被扔到的地方被其他生物或物件占据，或者周围的空间不足以容纳该雕像变成的生物，则它将不会变成生物。
雕像变成的生物对你和你的盟友态度为友好【态度】。它能听懂你的语言并会按你的口头命令行事，使用你的先攻并在你回合结束后立即执行其回合。如果你不下达任何命令，则该生物会保护自己而不作其他动作。
生物存在的时间依雕像而不同。持续时间结束时，生物将变回异能塑像形态。当它的生命值降至0，或是你在触碰它期间用一个魔法动作令其变回雕像时，它亦将提前变回雕像状态。变回雕像后，异能塑像的词条必须经过一段时间后才能再次启动（见下文描述）。
【象牙山羊（珍稀）】
这种象牙制成的山羊雕像总是三个为一组制造。每个山羊雕像都有独特的外形和功能，如下所述：
- 【可怖山羊】该塑像可以变为一只巨山羊并至多维持3小时。它无法发动攻击，但你可以（不造成伤害地）卸下它的角作为武器。其中一只角变为+1 骑枪，而另一只角则变为+2 长剑 。卸下一只角需要一个魔法动作。当山羊变回雕像时，角变成的武器也将随之消失，而山羊的角会恢复原状。另外，当你骑乘这头巨山羊时，它将散发出30尺半径的光环 [效应区域]，任何在光环范围内开始其回合的敌对【态度】生物都必须进行一次DC 15的感知豁免，豁免失败则陷入恐慌状态1分钟，当你不再骑乘山羊、或是山羊变回雕像后该恐慌也会提前结束。该受恐慌生物可以在它的每个回合结束时再次进行该豁免，成功则终止其身上的该效应。生物豁免成功时，它将在随后的24小时里免疫该效应。使用后，此雕像需要经过15日才能再次启动。
- 【客运山羊】该塑像可以变为一只数据和乘用马相同的大型山羊。它有24发充能，处于野兽形态下时每小时（不足1小时按1小时计）将消耗1发充能。只要雕像还有充能，你就能随意使用它。当充能耗尽时，它将变回雕像且需要等到7日后充能完全恢复时才能再次启动。
- 【苦力山羊】该塑像可以变为一只巨山羊 ，其存在至多维持3小时。使用后，此雕像需要经过30日才能再次启动。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 24 发充能：花充能写 `cost: [{ resource: '物品充能:异能塑像，象牙山羊', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:异能塑像，象牙山羊', name: '异能塑像，象牙山羊', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:异能塑像，象牙山羊' }]`（一件物品有好几种次数，就用 '物品次数:异能塑像，象牙山羊:<短名>'）。

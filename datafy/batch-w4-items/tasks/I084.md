# 任务 I084：链条

- 条目键：`XPHB:item:链条`
- 出处：冒险装备

## 原文

以一个操作动作，你可以进行一次DC 13的力量（运动）检定。如果该检定成功，你能利用链条捆住一个位于你5尺内的非自愿生物，但该生物必须处于受擒、失能或束缚状态。如果你绑住了该生物的腿，该生物陷入束缚状态，直至挣脱。挣脱链条需要该生物使用动作来通过一次DC 18的敏捷（特技）检定。扯坏链条需要该生物使用动作来通过一次DC 20的力量（运动）检定。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:链条', name: '链条', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:链条' }]`（一件物品有好几种次数，就用 '物品次数:链条:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

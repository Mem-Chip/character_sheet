# 任务 I021：吸矢盾

- 条目键：`XDMG:item:吸矢盾`
- 出处：魔法物品（珍稀，需同调）

## 原文

持握此盾牌期间，你对抗远程攻击的护甲等级具有+2加值。该加值将加在盾牌通常提供的加值上。
此外，当一个攻击者对你周围5尺内的目标发动远程攻击时，你可以执行反应以替代该目标成为此次攻击的目标。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:吸矢盾', name: '吸矢盾', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:吸矢盾' }]`（一件物品有好几种次数，就用 '物品次数:吸矢盾:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

# 任务 I265：火球项链

- 条目键：`XDMG:item:火球项链`
- 出处：魔法物品（珍稀）

## 原文

这条项链挂着1d6 + 3颗珠子。你可以执行魔法动作取下一颗珠子并将其投掷最多60尺距离。珠子会在投掷轨迹的末端引爆，效果等同于3环火球术（豁免DC 15）。
你可以同时把多枚珠子，甚至把整条项链一起投掷出去。这么做时，每有一颗额外投掷出的珠子，火球术的伤害就增加1d6点（最大12d6）。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:火球项链', name: '火球项链', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:火球项链' }]`（一件物品有好几种次数，就用 '物品次数:火球项链:<短名>'）。

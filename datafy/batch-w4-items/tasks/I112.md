# 任务 I112：异界之门魔方

- 条目键：`XDMG:item:异界之门魔方`
- 出处：魔法物品（传说）

## 原文

这个边长3寸的立方体散发着明显的魔法能量。立方体的六个面分别连接到六个不同的存在位面，其中一面连接的是物质位面，而其他面所连接的位面则由DM决定。
立方体具有3充能，并在每日黎明时重获1d3已消耗的充能。以一个魔法动作，你可以消耗此立方体的1充能，从立方体中施展下列法术之一。
【大门】
按压立方体的其中一面，你施展法术异界之门，打开连接到对应存在位面的传送门。
【位面转移】
按压两次立方体的其中一面，你施展法术位面转移，将目标传送至对应存在位面。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:异界之门魔方`：异界之门魔方（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:异界之门魔方', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:异界之门魔方', name: '异界之门魔方', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:异界之门魔方' }]`（一件物品有好几种次数，就用 '物品次数:异界之门魔方:<短名>'）。

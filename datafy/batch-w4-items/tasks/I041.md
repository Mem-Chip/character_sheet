# 任务 I041：矮人腰带

- 条目键：`XDMG:item:矮人腰带`
- 出处：魔法物品（珍稀，需同调）

## 原文

穿戴此腰带期间，你获得以下增益：
- 【矮人语】你懂得矮人语。
- 【矮人之友】你进行与矮人和灰矮人互动的魅力（游说）检定时具有优势。
- 【刚毅】你的体质提升2，至多提升至20。
- 此外，与此腰带同调期间，如果你能够长出胡须，则在每天的黎明时分你有50%的概率长出一大把胡子；如果你已经长有胡须，则你的胡须会明显变得更厚。
- 如果你不是一名矮人或灰矮人，你在着装此腰带期间获得以下额外的增益：
- 【黑暗视觉】你拥有 60 尺黑暗视觉。
- 【韧性】你具有毒素伤害的抗性。此外，你为避免/结束中毒状态所做的豁免检定具有优势。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:矮人腰带', name: '矮人腰带', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:矮人腰带' }]`（一件物品有好几种次数，就用 '物品次数:矮人腰带:<短名>'）。

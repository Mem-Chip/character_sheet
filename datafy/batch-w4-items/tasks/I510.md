# 任务 I510：诸界之井

- 条目键：`XDMG:item:诸界之井`
- 出处：魔法物品（传说）

## 原文

这块如丝绸般顺滑的精致黑色布料，折叠起来只有手帕大小。布料展开后为直径6尺的圆形盖布。
你能够以一个魔法动作展开诸界之井，将它布置在坚实表面上，产生一扇直径6尺、通向另一个世界或存在位面的圆形双向传送门。每次此物品打开传送门时，由DM决定它所连接的地方。传送门保持开启，直至位于其5尺内的一名生物以一个魔法动作抓住布料的边缘把它折叠起来，来将传送门关闭。
诸界之井一经使用，在1d8小时内都无法再次打开传送门。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:诸界之井', name: '诸界之井', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:诸界之井' }]`（一件物品有好几种次数，就用 '物品次数:诸界之井:<短名>'）。

# 任务 I509：波涛

- 条目键：`XDMG:item:波涛`
- 出处：魔法物品（神器，需同调）

## 原文

波涛藏在白羽山的地下城中，这把精致的三叉戟上面雕有波浪、贝壳和海洋生物的图案。
你用此魔法武器进行的攻击检定和伤害掷骰获得+3加值。当你在以此武器进行的攻击检定的d20中掷出20时，目标额外受到21暗蚀伤害。
持用波涛期间，你获得以下增益：
- 【战斗预备】你能够进行有优势的先攻掷骰。
- 【水下适应】你身处水下期间，一个空气泡泡环绕着你的脑袋，令你可以在该环境下如常呼吸。
【命令水栖】
波涛具有3充能并在每日黎明时重获1d3充能，当你携带波涛时，你可以消耗1充能，对一只具有游泳速度的野兽施展支配野兽 （豁免DC 20）。
【法术无效结界】
持握波涛时，你可以从中施展九环版本的法术法术无效结界。该词条一经使用，直至次日黎明你都无法再次使用。
【智能】
涛是一把具有绝对中立阵营的智能武器，智力为14，感知10，魅力18。它具有120尺听觉及120尺黑暗视觉。
波涛与其持用者通过心灵感应交流，波涛也会说水族语。
【个性】
波涛热衷于劝诫凡人信仰海神，并有哼唱船歌的习惯。如果其持用者没有将波涛的目标传遍世界，波涛将进行反噬。
【摧毁波涛】
波涛只会在雷铸岛——其被锻造出来的地方——被摧毁。波涛只能由风暴巨人或拥有着风暴巨人力量之人亲手熔化。摧毁波涛将激怒一位海神，其将派遣强大的使徒们攻打小岛并惩罚将波涛摧毁之人。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:波涛`：波涛（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:波涛', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:波涛', name: '波涛', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:波涛' }]`（一件物品有好几种次数，就用 '物品次数:波涛:<短名>'）。

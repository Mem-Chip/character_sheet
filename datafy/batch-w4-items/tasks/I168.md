# 任务 I168：光彩夺目宝石

- 条目键：`XDMG:item:光彩夺目宝石`
- 出处：魔法物品（非普通）

## 原文

这块棱形宝石有50发充能。持握该宝石时，你可以用一个魔法动作来使用宝石的三个命令语之一，造成如下效应：
- 【第一命令语】宝石发出亮光，提供30尺的明亮光照和其外30尺的微光光照。该效应不会消耗充能。此效应将持续到你用一个附赠动作再次说出该命令语，或你使用宝石的另一能力为止。
- 【第二命令语】你消耗1发充能，令宝石向60尺内你能看见的一个生物发出一道耀眼的光束。该生物必须成功通过一次DC 15的体质豁免否则陷入目盲状态1分钟。该生物在其每个回合结束时可以重复此豁免，豁免成功则结束其身上的此效应。
- 【第三命令语】你消耗5发充能，令宝石以自身为原点对30尺锥状 [效应区域]区域放出刺眼的光芒。锥状 [效应区域]区域内的每个生物必须进行豁免，如同它们被以第二命令语创造的射线击中一般。
耗尽充能后，此宝石变为价值50gp的非魔法宝石。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:光彩夺目宝石`：光彩夺目宝石（充能 50）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 50 发充能：花充能写 `cost: [{ resource: '物品充能:光彩夺目宝石', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:光彩夺目宝石', name: '光彩夺目宝石', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:光彩夺目宝石' }]`（一件物品有好几种次数，就用 '物品次数:光彩夺目宝石:<短名>'）。

# 任务 I246：恐惧之锤

- 条目键：`XDMG:item:恐惧之锤`
- 出处：魔法物品（珍稀，需同调）

## 原文

这把魔法武器具有3充能，并在每日黎明时重获1d3已消耗的充能。持握这把武器期间，你可以使用一个魔法动作并消耗1充能，来从该武器中释放出一股恐惧波动。30尺内每个你所选择的生物都必须成功通过一次DC 15的感知豁免，否则将陷入恐慌状态，持续1分钟。以这种方式陷入恐慌的生物在其回合内必须尽可能的向远离你的方向移动，并且它不能发动借机攻击。它只能选择进行疾走动作，或尝试摆脱一个阻止其移动的效应。如果无处可逃，则它可以执行回避动作。该生物在每个自己的回合结束时可以再次进行此豁免，豁免成功则其身上的该效应提前结束。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:恐惧之锤`：恐惧之锤（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:恐惧之锤', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:恐惧之锤', name: '恐惧之锤', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:恐惧之锤' }]`（一件物品有好几种次数，就用 '物品次数:恐惧之锤:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

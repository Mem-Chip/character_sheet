# 任务 I116：无尽水瓶

- 条目键：`XDMG:item:无尽水瓶`
- 出处：魔法物品（非普通）

## 原文

这个带瓶塞的瓶子在摇晃时会发出液体晃动的声音，仿佛其中有水一般。此瓶重2磅。
你可以用一个魔法动作拔出瓶塞并说出其三个命令语之一，使瓶中涌出淡水或咸水（由你选择）。水将在你的下一回合开始时停止涌出。从下列命令语中进行选择：
- 【溅射】此瓶产生1加仑的水。
- 【喷泉】此瓶产生5加仑的水。
- 【井喷】此瓶产生30加仑的水，以一道长30尺，宽1尺的线状 [效应区域]水柱的形式喷涌而出。如果你正握持着此瓶，那么你可以将瓶口对准一处地方（无需动作）。你选择该线状 [效应区域]内你的一名生物，该生物必须成功通过一次DC 13的力量豁免，否则受到1d4点钝击伤害并陷入倒地状态。除瞄准生物以外，你也可以用瓶口瞄准线状 [效应区域]内一个不超过200磅，且未被着装或携带的物件。该物件将被水柱打翻。

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。

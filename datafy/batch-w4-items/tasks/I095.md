# 任务 I095：万众时尚斗篷

- 条目键：`XDMG:item:万众时尚斗篷`
- 出处：魔法物品（普通）

## 原文

着装此斗篷期间，你可以用一个附赠动作改变它的样式、颜色、及外表品质。这件斗篷的重量不会因此改变，且不论它的外观如何，这件斗篷永远只能是一件斗篷而不是别的东西。当然，这件斗篷可以用于复制其他魔法斗篷的外观，但它不会因此具有任何其他魔法斗篷的魔法能力。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:万众时尚斗篷', name: '万众时尚斗篷', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:万众时尚斗篷' }]`（一件物品有好几种次数，就用 '物品次数:万众时尚斗篷:<短名>'）。

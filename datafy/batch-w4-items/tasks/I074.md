# 任务 I074：祈神蜡烛

- 条目键：`XDMG:item:祈神蜡烛`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

你可以用一个魔法动作点燃蜡烛，此时它的魔力便会被激活。蜡烛共可以燃烧4小时，你也可以提前吹灭蜡烛以备将来之用。以分钟为单位计算蜡烛已燃烧时间，并从总时间内扣除。
蜡烛燃烧期间，它会散发出半径30尺范围的微光光照光照。位于此光照范围内期间，你所进行的D20 检定具有优势。此外，此光照范围内的牧师和德鲁伊在施展它们准备了的1环法术时无需消耗法术位。
另外，当你首次点亮祈神蜡烛时，你可以用它施展一次法术异界之门。这样做会立刻摧毁这根蜡烛，而此法术所创造的传送门会连接至某一特定的外层位面，由DM选择或掷以下表格决定：

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:祈神蜡烛' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:祈神蜡烛', name: '祈神蜡烛', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:祈神蜡烛' }]`（一件物品有好几种次数，就用 '物品次数:祈神蜡烛:<短名>'）。

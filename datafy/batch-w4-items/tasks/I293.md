# 任务 I293：启蒙花盆

- 条目键：`XDMG:item:启蒙花盆`
- 出处：魔法物品（普通）

## 原文

你可以在这个10磅重的黏土花盆里种植一株普通灌木，待其生长30天后，这株灌木会魔法性的转化为一株启蒙灌木 。当灌木被启蒙时，它的根系会打碎花盆，并导致花盆被摧毁。
这株启蒙灌木会对你友好【态度】并服从你的命令。如果没有你的命令，它会什么也不做。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:启蒙花盆', name: '启蒙花盆', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:启蒙花盆' }]`（一件物品有好几种次数，就用 '物品次数:启蒙花盆:<短名>'）。

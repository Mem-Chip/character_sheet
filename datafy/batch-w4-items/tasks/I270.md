# 任务 I270：以太化之油

- 条目键：`XDMG:item:以太化之油`
- 出处：魔法物品（珍稀）

## 原文

一扁瓶的以太化之油可以覆盖住连带着其着装与携带的装备的一个中型或小型生物（生物体型每比中型大一级，就需要多用一扁瓶）。抹上油需要花费10分钟。被影响的生物将会获得以太化法术的效应，持续1小时。
与瓶中油膏类似的浑浊的灰色油珠会在其容器的外壁形成，并迅速蒸发。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品:以太化之油`：以太化之油（数量）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:以太化之油' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:以太化之油', name: '以太化之油', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:以太化之油' }]`（一件物品有好几种次数，就用 '物品次数:以太化之油:<短名>'）。

# 任务 I465：雷霆法杖

- 条目键：`XDMG:item:雷霆法杖`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

这根法杖可被用作一根魔法长棍（用这根长棍发动的攻击检定和伤害掷骰获得+2加值）。它具有以下额外词条。其中的某项词条一经使用，直至次日黎明前你都无法再次使用。
【电闪】
当你用法杖发动近战攻击并命中时，你可以对目标造成额外2d6点闪电伤害（无需动作）。
【雷鸣】
当你用法杖发动近战攻击并命中时，你可以让法杖爆发出距你300尺内都能听见的雷霆巨响（无需动作）。被你击中的目标必须通过一次DC 17的体质豁免，否则陷入震慑状态，持续至你的下个回合结束。
【雷霆】
当你用法杖发动近战攻击并命中时，你可以立刻执行附赠动作来同时使用电闪和雷鸣词条（见上文）。这样做只会消耗雷霆词条的使用次数，而不会消耗电闪或雷鸣的使用次数。
【闪电打击】
你可以执行魔法动作，让法杖从尖端射出一道覆盖宽5尺，长120尺线状区域的线状 [效应区域]闪电束。所有在该线状 [效应区域]区域内的生物都需要进行DC 17的敏捷豁免，豁免失败则其受到9d6闪电伤害，豁免成功则伤害减半。
【惊雷】
你可以执行魔法动作，让法杖制造一记在你600尺内都能听见的惊雷声响。以你为源点60尺光环 [效应区域]区域内的所有生物都需要进行DC 17的体质豁免。豁免失败则其受到2d6雷鸣伤害并陷入耳聋状态，持续1分钟；豁免成功则仅受半伤。

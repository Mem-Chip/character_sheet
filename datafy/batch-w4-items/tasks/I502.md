# 任务 I502：麻痹魔杖

- 条目键：`XDMG:item:麻痹魔杖`
- 出处：魔法物品（珍稀，需同调）

## 原文

这根魔杖具有7充能。持握它时，你可以执行魔法动作并消耗1充能，从魔杖尖端向位于你60尺内的一个你可见的生物射出一发纤细的蓝色光线。目标必须成功通过一次DC 15的体质豁免，否则将陷入麻痹状态一分钟。目标在其每回合结束时可以重新进行该豁免，豁免成功则终止其身上的该效应。
【重获充能】
这根魔杖在每日黎明时重获1d6 + 1已消耗的充能。当充能数耗尽时，骰一次1d20。如果骰值为1，魔杖将化作飞灰并被摧毁。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:麻痹魔杖`：麻痹魔杖（充能 7）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 7 发充能：花充能写 `cost: [{ resource: '物品充能:麻痹魔杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:麻痹魔杖', name: '麻痹魔杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:麻痹魔杖' }]`（一件物品有好几种次数，就用 '物品次数:麻痹魔杖:<短名>'）。

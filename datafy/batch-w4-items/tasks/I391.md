# 任务 I391：警示权杖

- 条目键：`XDMG:item:警示权杖`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

这根权杖具有以下词条：
【警觉】
当你持握此权杖时，你在感知（察觉）检定和先攻掷骰上具有优势。
【法术】
当你持握此权杖时，你可以通过它施放以下法术：
- 侦测善恶
- 侦测魔法
- 侦测毒性和疾病
- 识破隐形
【防护灵光】
以一个魔法动作，你可以将权杖的柄端插入地面，此时权杖的顶部将发出60尺半径的明亮光照和额外60尺微光光照。身处权杖发出的明亮光照中时，你与你的盟友在护甲等级和豁免中获得+1加值，并且可以感知到同样处于此明亮光照中的任何隐形生物的位置。
最多10分钟后或直至一个生物执行魔法动作将权杖从地面拔出后，权杖顶部会停止发光并结束这个效应。该词条一经使用，直至次日黎明前你都无法再次使用。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:警示权杖', name: '警示权杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:警示权杖' }]`（一件物品有好几种次数，就用 '物品次数:警示权杖:<短名>'）。

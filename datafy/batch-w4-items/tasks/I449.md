# 任务 I449：通灵板

- 条目键：`XDMG:item:通灵板`
- 出处：魔法物品（非常珍稀）

## 原文

这块华丽木板的一面印有通用语字母表的字符，旁边还有"是"和"否"的字样，以及代表"吉"和"凶"的符号。通灵板配有一块心型的木制占卜板。这块占卜板必须放置在通灵板有字母的一面，才能让通灵板的魔法发挥作用。
通灵板具有3充能，并在每日黎明时重获1已消耗的充能。施展法术时，你可以召唤死者灵魂引导占卜板在木板表面滑动，并通过指向木板上的字母或单词来回答你的问题。触摸占卜板期间，你可以花费1分钟施展一个法术，能施展的法术与所需充能如下表所示。
| 法术 | 消耗充能 |
| 卜筮术 | 1 |
| 通神术 | 3 |

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:通灵板`：通灵板（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:通灵板', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:通灵板', name: '通灵板', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:通灵板' }]`（一件物品有好几种次数，就用 '物品次数:通灵板:<短名>'）。

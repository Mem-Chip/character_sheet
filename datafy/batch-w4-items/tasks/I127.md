# 任务 I127：喷嚏粉

- 条目键：`XDMG:item:喷嚏粉`
- 出处：魔法物品（非普通）

## 原文

这种粉末通常被装在小盒子里，其分量足够使用一次。这种粉末看起来像是无踪粉，对其施展鉴定术也会给出这样的结果。
你可以用操作动作把这种粉末洒向空中，迫使你和你周围30尺光环 [效应区域]内的生物进行一次DC 15的体质豁免，构装、元素、泥怪、植物和亡灵在豁免中自动成功。
豁免失败者将不停打喷嚏，陷入失能并窒息。受影响的生物能在每次自己的回合结束时再次进行该豁免。一旦豁免成功，其自己身上的效应也将随之终止。法术次等复原术也可以终止一名生物身上的该效应。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:喷嚏粉', name: '喷嚏粉', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:喷嚏粉' }]`（一件物品有好几种次数，就用 '物品次数:喷嚏粉:<短名>'）。

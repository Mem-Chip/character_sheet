# 任务 I267：捕网

- 条目键：`XPHB:item:捕网`
- 出处：冒险装备

## 原文

当你执行攻击动作，你可以将你的一次攻击替换为丢出一张捕网。你可以选择位于你15尺内可见的一个生物作为目标。该目标必须通过一次敏捷豁免（DC 8+你的敏捷调整值+你的熟练），否则陷入束缚状态，直至挣脱。体型是巨型及以上的目标将自动通过豁免。
被束缚的目标或者位于目标5尺内的生物，可以通过一个动作来进行一次DC 10的力量（运动）检定来挣脱捕网。若检定成功，被束缚的生物将被解放。摧毁捕网（AC 10；5 HP；免疫钝击、毒素和心灵伤害）也能解放被困目标并结束捕网的效果。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:捕网', name: '捕网', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:捕网' }]`（一件物品有好几种次数，就用 '物品次数:捕网:<短名>'）。

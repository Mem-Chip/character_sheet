# 任务 I128：矮人飞锤

- 条目键：`XDMG:item:矮人飞锤`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

你用该魔法武器发动的攻击检定和伤害掷骰获得+3加值。它具有T属性，常规射程为20尺，最大射程为60尺。当你用此武器发动远程攻击命中时，它将造成1d8的额外力场伤害。如果命中的目标是一个生物类型为巨人的生物，则额外伤害提升为2d8。攻击后，此武器将立即飞回你的手中。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:矮人飞锤', name: '矮人飞锤', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:矮人飞锤' }]`（一件物品有好几种次数，就用 '物品次数:矮人飞锤:<短名>'）。

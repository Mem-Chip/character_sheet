# 任务 I110：力场魔方

- 条目键：`XDMG:item:力场魔方`
- 出处：魔法物品（珍稀，需同调）

## 原文

这个立方体棱长约1寸，每个面上都有不同的标记。你可以按下立方体某一面，并消耗如下表所示的充能以施展对应的法术（豁免DC 17）。
该立方体共有10发充能，每天黎明时会恢复1d6发已消耗的充能次数。
【力场魔方各面效果】
| 法术 | 消耗充能 |
| 法师护甲 | 1 |
| 护盾术 | 1 |
| 李欧蒙小屋 | 3 |
| 魔邓肯私人密室 | 4 |
| 欧提路克弹力法球 | 4 |
| 力场墙 | 5 |

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:力场魔方`：力场魔方（充能 10）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 10 发充能：花充能写 `cost: [{ resource: '物品充能:力场魔方', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:力场魔方', name: '力场魔方', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:力场魔方' }]`（一件物品有好几种次数，就用 '物品次数:力场魔方:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

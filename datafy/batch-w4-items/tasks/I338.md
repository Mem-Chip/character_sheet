# 任务 I338：夸尔羽符，鸟

- 条目键：`XDMG:item:夸尔羽符，鸟`
- 出处：魔法物品（珍稀）

## 原文

这枚物件看上去像一根羽毛。
你可以执行魔法动作将羽符抛至5尺高的空中。羽符将消失，并且一只五彩斑斓的巨鸟取而代之。这只鸟使用鹏鸟的数据，但它无法进行攻击。它会遵从你的简单命令且能在负载至多500磅的同时全速前进（16里/小时，每飞行3小时休息1小时，最高144里/日），或在负载至多1000磅的同时以半速前进。鸟将在达到其一日能飞行的最远距离或生命值降为0时消失。你也可以用魔法动作将其遣散。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:夸尔羽符，鸟', name: '夸尔羽符，鸟', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:夸尔羽符，鸟' }]`（一件物品有好几种次数，就用 '物品次数:夸尔羽符，鸟:<短名>'）。

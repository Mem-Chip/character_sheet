# 任务 I184：巫术帽

- 条目键：`XDMG:item:巫术帽`
- 出处：魔法物品（普通，需同调）

## 原文

这顶锥形帽上点缀着星月。你着装此帽期间，你获得下述增益。
【法器】
你可以将其作为你施展法师法术的法器。
【未知法术】
你可以用一个魔法动作尝试施展一道你并未已知的戏法。所选戏法必须位于法师法表中，并且其施法时间必须为动作。你进行一次DC 10的智力（奥秘）检定。检定成功，则你施展那道法术。检定失败，则你施法失败，用于施法的动作被浪费。无论检定成功与否，此词条一经使用，直到你完成一次长休之前不能再次使用。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:巫术帽', name: '巫术帽', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:巫术帽' }]`（一件物品有好几种次数，就用 '物品次数:巫术帽:<短名>'）。

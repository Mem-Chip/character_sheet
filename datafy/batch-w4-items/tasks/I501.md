# 任务 I501：奥喀斯之杖

- 条目键：`XDMG:item:奥喀斯之杖`
- 出处：魔法物品（神器，需同调）

## 原文

这根阴森恐怖的魔杖由奥喀斯制作并使用。它不时从其恶魔领主创造者的手中溜走，神奇地出现在恶魔领主感到有机会实现其邪恶目的的地方。
这根魔杖的顶端镶嵌着一颗曾属于一位被奥喀斯所杀的人类英雄的颅骨。魔杖可以魔法般地改变体型以更好地适应使用者的握持。魔杖10尺范围内的所有圣水都会被摧毁。
除奥喀斯外，任何生物与魔杖进行同调时，必须进行一次DC 17的体质豁免。豁免成功，则该生物受到10d6暗蚀伤害。豁免失败，则该生物死亡，若其是类人，则变为一只丧尸 。
【魔化武器】
你可以将魔杖用作一把魔法硬头锤，用魔杖进行的攻击检定和伤害掷骰获得+3加值，魔杖命中时，额外造成2d12暗蚀伤害。
【随机词条】
奥喀斯之杖具有下列随机词条：
- 2项神器词条; 次要增益词条词条
- 1项神器词条; 主要增益词条词条
- 2项神器词条; 次要减益词条词条
- 1项神器词条; 主要减益词条词条
与奥喀斯维持同调期间，魔杖的减益词条将被抑制。
【守护】
持握魔杖时，你的护甲等级获得+3加值。
【法术】
魔杖具有7充能并在每日黎明时重获1d4 + 3已消耗的充能。你可以从中施展下表中的法术（豁免DC 18）。表中表明了你施展对应的法术需要消耗多少充能。
| 法术 | 消耗充能 |
| 活化死尸 | 1 |
| 枯萎术 | 2 |
| 死亡法阵 | 3 |
| 死亡一指 | 3 |
| 律令死亡 | 4 |
| 死者交谈 | 1 |
奥喀斯与受其祝福的追随者与魔杖维持同调期间，他们施展以上每个法术的充能消耗降低2（最低为0）。
【唤起不死生物】
持握魔杖期间，你能够以魔法动作咒唤15只丧尸和15具骷髅 ，这些亡灵将魔法的自地面中升起或在你300尺内的未占据空间中生成，它们将服从你的命令，它们被摧毁或次日黎明时，它们会倒塌为一堆无生命的骨头和腐尸。该词条一经使用，直至次日黎明你都无法再次使用。
奥喀斯在持握魔杖期间可以召唤任意种类的亡灵，而非仅仅是丧尸和骷髅。这些亡灵不会在次日黎明消亡，而是存在直至奥喀斯将他们驱散。
【智能】
奥喀斯之杖是一根混乱邪恶的智能魔杖，智力为16，感知12，魅力16。它具有120尺听觉及120尺黑暗视觉。
奥喀斯之杖说通用语和炼狱语并可以通过心灵感应与持用者交流。
【个性】
魔杖的目标是满足奥喀斯杀戮多元宇宙一切的欲望。魔杖残暴，虚无，且毫无幽默感。
为了进一步完成奥喀斯的目标，魔杖会假装忠诚于其现任使用者，甚至给对方许下根本不打算应允的承诺，比如发誓帮助对方推翻奥喀斯本尊。
【摧毁法杖】
要摧毁奥喀斯之杖 ，需要魔杖上骷髅头的英雄本尊将其带到正能量位面。要做到这点，必须先让这位故去已久的英雄重新复活——这并非易事，奥喀斯囚禁了他的灵魂，藏在一个守备森严的秘密地点。
将魔杖浸没在正能量（例如弥漫在正位面的正能量）中将导致其崩坏炸裂，但如果无法满足上述的前提条件，破坏的魔杖将立即在奥喀斯所控制的深渊层域中重新形成。

## 可以花的资源（cost 里的 resource 只能用这些 id）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 7 发充能：花充能写 `cost: [{ resource: '物品充能:奥喀斯之杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:奥喀斯之杖', name: '奥喀斯之杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:奥喀斯之杖' }]`（一件物品有好几种次数，就用 '物品次数:奥喀斯之杖:<短名>'）。

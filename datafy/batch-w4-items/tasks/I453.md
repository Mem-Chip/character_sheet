# 任务 I453：魅惑法杖

- 条目键：`XDMG:item:魅惑法杖`
- 出处：魔法物品（珍稀，需同调）

## 原文

这根法杖具有10充能。持握这根法杖期间，你可以使用以下词条：
- 【施法】你可以消耗1充能，从法杖中施展魅惑类人、命令术、或通晓语言 ，该法术使用你自己的法术豁免DC。
- 【惑控反射】如果一道惑控学派法术仅以你为目标，而你豁免成功时，你可以执行反应并消耗1充能，将法术反射给原施法者，如同你施展了这道法术一般。
- 【惑控抵抗】如果一道惑控学派法术仅以你为目标，而你豁免失败时，你可以将失败的豁免改为成功。法杖的这项词条一经使用，其直至次日黎明前都无法再次使用。
【重获充能】
这根法杖在每日黎明时重获1d8 + 2已消耗的充能。当充能数耗尽时，骰一次1d20。如果骰值为1，法杖将崩解为尘土，并被摧毁。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:魅惑法杖`：魅惑法杖（充能 10）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 10 发充能：花充能写 `cost: [{ resource: '物品充能:魅惑法杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:魅惑法杖', name: '魅惑法杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:魅惑法杖' }]`（一件物品有好几种次数，就用 '物品次数:魅惑法杖:<短名>'）。

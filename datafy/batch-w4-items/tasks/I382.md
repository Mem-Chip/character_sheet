# 任务 I382：X射线戒指

- 条目键：`XDMG:item:X射线戒指`
- 出处：魔法物品（珍稀，需同调）

## 原文

着装此戒指期间，你可以执行魔法动作以获得范围30尺的X射线视觉，持续1分钟。对你来说，半径内的固态物件变为透明，并且不会阻碍光线通过。这种视觉可以穿透1尺厚的石头，1寸厚的常见金属或最多3尺厚的木头或泥土。更厚的物质或一张薄铅片会阻挡这种视觉。
每当你在完成一次长休前再次使用这枚戒指时，你必须成功通过一次DC 15的体质豁免，否则获得1级力竭。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:X射线戒指', name: 'X射线戒指', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:X射线戒指' }]`（一件物品有好几种次数，就用 '物品次数:X射线戒指:<短名>'）。

# 任务 I180：维克那魔掌

- 条目键：`XDMG:item:维克那魔掌`
- 出处：魔法物品（神器，需同调）

## 原文

维克那是一名强大的法师。他行使魔法之力征讨，建立了一个恐怖的大帝国。然而，拥有强大力量的维克依然畏惧死亡，他采取手段，通过成为巫妖阻拦死亡的脚步。
一名名为凯斯的将军发动了叛乱，并在一场骇人的战争中结束了维克那的统治，维克那剩下的只有一只手掌和一只眼睛，这些可怖的神器仍试图在世上贯彻维克纳的意志。
维克那法眼和维克那魔掌Hand of Vecna 是独立的神器，可能一起出现也可能被分开发现。法眼布满血丝，有如刚刚直接从眼眶中抽出。魔掌则是风干萎缩的左肢。
【法眼与魔掌的随机词条】
维克纳魔掌具有下列随机词条：
- 1项神器词条; 次要增益词条词条
- 1项神器词条; 主要增益词条词条
- 1项神器词条; 次要减益词条词条
【同调魔掌】
要与魔掌进行同调，你必须将魔掌压在左手断肢的截面。魔掌会自行嫁接入你的手臂并成为一副正常运作的前肢。此后魔掌一旦被取下，你将立即死亡。
【魔掌词条】
与魔掌维持同调期间，你的阵营为中立邪恶，且你获得以下增益：
- 【超级力量】你的力量变为20，除非其已是20或更高。
- 【极寒之抚】任意你以魔掌进行的近战法术攻击或你以魔掌持握的武器进行的近战攻击命中时，额外造成2d8寒冷伤害。
- 【施法】魔掌具有8充能，并在每日黎明时重获1d4 + 4已消耗的充能。你能以魔掌施展维克那魔掌法术表中的法术（豁免DC 18）。表中表明了你施展对应的法术需要消耗多少充能。每当你以魔掌施展法术时，魔掌会对你施展暗示术（豁免DC 18，无需专注）要求你犯下恶行。魔掌可能对恶行有特定的要求，或是由你决定具体的行为。 【维克那魔掌法术】 | 法术 | 消耗充能 | | 死亡一指 | 5 | | 睡眠术 | 1 | | 缓慢术 | 2 | | 传送术 | 3 |
【摧毁法眼和魔掌】
如果维克那法眼和维克那魔掌与同一生物维持同调，并且该生物被凯斯之剑斩杀，则法眼和魔掌即时迸出火焰烧成灰烬，并且被摧毁。任何其他摧毁法眼和魔掌的尝试似乎也是可行的，但这些神器会在维克那的其中一个隐藏宝库中重现，等着再临人间。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 8 发充能：花充能写 `cost: [{ resource: '物品充能:维克那魔掌', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:维克那魔掌', name: '维克那魔掌', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:维克那魔掌' }]`（一件物品有好几种次数，就用 '物品次数:维克那魔掌:<短名>'）。

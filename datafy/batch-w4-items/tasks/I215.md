# 任务 I215：吟游诗人乐器，奥莱姆竖琴

- 条目键：`XDMG:item:吟游诗人乐器，奥莱姆竖琴`
- 出处：魔法物品（传说，需同调）

## 原文

吟游诗人乐器在各方面都优于普通乐器。吟游诗人乐器共有七种，每种都以一所吟游诗人学院的名字命名。在未与乐器完成同调的情况下，尝试演奏乐器的生物必须进行一次DC 15的感知豁免，豁免失败则会受到2d4心灵伤害。
你可以通过演奏奥莱姆竖琴来施展以下法术之一：飞行术、隐形术、浮空术、防护善恶、困惑术、操控天气和火焰风暴。一旦该奥莱姆竖琴被用来施展了某一个法术，则其直至次日黎明前都无法再被用来施展该法术。这些法术使用你的施法属性和法术豁免DC。

## 可以花的资源（cost 里的 resource 只能用这些 id）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:吟游诗人乐器，奥莱姆竖琴', name: '吟游诗人乐器，奥莱姆竖琴', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:吟游诗人乐器，奥莱姆竖琴' }]`（一件物品有好几种次数，就用 '物品次数:吟游诗人乐器，奥莱姆竖琴:<短名>'）。

# 任务 I245：打击之锤

- 条目键：`XDMG:item:打击之锤`
- 出处：魔法物品（珍稀）

## 原文

你使用这把魔法武器进行的攻击检定和伤害掷骰具有+1加值。如果你使用这把武器攻击一个构装生物，则加值提升为+3。
当你使用这把武器进行一次攻击检定并掷出20时，目标会额外受到7钝击伤害。如果目标为构装生物，则其受到的额外钝击伤害为14。如果一个构装生物因受到该伤害而生命值被降至25及以下，则该生物被摧毁。

## 可以花的资源（cost 里的 resource 只能用这些 id）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:打击之锤', name: '打击之锤', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:打击之锤' }]`（一件物品有好几种次数，就用 '物品次数:打击之锤:<短名>'）。

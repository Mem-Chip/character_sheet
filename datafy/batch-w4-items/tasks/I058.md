# 任务 I058：速度之靴

- 条目键：`XDMG:item:速度之靴`
- 出处：魔法物品（珍稀，需同调）

## 原文

着装这双靴子期间，你可以使用一个附赠动作来互击脚后跟。若如此做，你的速度将加倍，且任何生物对你发动借机攻击时都具有劣势。若再次互击脚后跟则该效应终止。
在你使用该靴子的词条共计10分钟后，其魔法效应将不再对你生效，直至你完成一次长休。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:速度之靴', name: '速度之靴', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:速度之靴' }]`（一件物品有好几种次数，就用 '物品次数:速度之靴:<短名>'）。

# 任务 I271：锐锋之油

- 条目键：`XDMG:item:锐锋之油`
- 出处：魔法物品（非常珍稀）

## 原文

一扁瓶的锐锋之油可以涂抹在一把近战武器或二十发弹药上，但只有在非魔法性且造成挥砍或穿刺伤害的近战武器或弹药上才能发挥效用。抹上油需要花费1分钟，那之后油将魔法性地渗入被涂抹的武器或弹药，将其变为+3武器或+3弹药。
这种透明的凝胶状油膏中掺杂着极其纤细而微小的银色碎片。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品:锐锋之油`：锐锋之油（数量）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:锐锋之油' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:锐锋之油', name: '锐锋之油', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:锐锋之油' }]`（一件物品有好几种次数，就用 '物品次数:锐锋之油:<短名>'）。

# 任务 I027：次元袋

- 条目键：`XDMG:item:次元袋`
- 出处：魔法物品（非普通）

## 原文

这个袋子有着比外表尺寸看起来更大的内部实际空间，从内部看，袋口约两平方尺，深约4尺，可以容纳至多500磅，体积不超过64立方尺的东西。无论装了什么，这个袋子总是重5磅。从袋子里取出东西需要花费一个操作动作。
如果次元袋超载，或是袋子被戳破、撕裂，它将因此被摧毁，它所装载的东西将散落到星界位面各处。如果袋子被内外翻转，则它所装载的东西将完好无损地掉落出来，但再次使用袋子之前必须将它恢复原状。次元袋内所容纳的空气量可供其内生物呼吸的分钟数为10除以袋内正在呼吸的生物数量，此后袋内的生物便开始窒息。
把次元袋放入霍华德便利袋、球状 [效应区域]或其他类似物品内时，将会立即同时摧毁两件物品并打开一扇通往星界位面的传送门扉。门扉产生于放入另一物品的第一件物品的所在地。任何在门扉周边10尺球状区域内的生物将被吸入门内，并送往星界位面中的随机地点。然后门扉即时关闭，门的通道是单向的且无法被再次打开。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:次元袋', name: '次元袋', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:次元袋' }]`（一件物品有好几种次数，就用 '物品次数:次元袋:<短名>'）。

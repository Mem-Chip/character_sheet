# 任务 I389：杂货法袍

- 条目键：`XDMG:item:杂货法袍`
- 出处：魔法物品（非普通）

## 原文

这件长袍上打着各种颜色和形状的补丁。着装这件长袍期间，你可以使用一个魔法动作拆下其中一块补丁，使其变成它所代表的物件或生物。当长袍上的所有补丁都被拆下后，它将变为一件平凡的衣物。
杂货法袍有着如下补丁各两个：
- 牛眼提灯（装满燃料且点燃）
- 匕首
- 镜子
- 长杆
- 绳索（卷起）
- 麻袋
此外，杂货法袍还有4d4个其他补丁。由DM选择补丁种类或通过在下表中掷骰以随机决定补丁种类。
| 1d100 | 补丁 |
| 01-08 | 装有100 gp的袋子 |
| 09-15 | 价值500GP的银柜（高1尺，宽、深各6寸） |
| 16-22 | 铁门（宽最多10尺、高最大10尺，且你选择的一面装有门闩），你可将其安置在一处你触及内的开口处，它将自动改变形状贴合开口并设置铰链。 |
| 23-30 | 10枚宝石，每枚价值100GP |
| 31-44 | 木梯（24尺长） |
| 45-51 | 一匹乘用马，配有一个乘坐乘用鞍座 |
| 52-59 | 露天陷坑（10尺立方 [效应区域]），你可将其布置在你周边10尺范围内的地面上 |
| 60-68 | 4 治疗药水 |
| 69-75 | 划艇（12尺长） |
| 76-83 | 记载有一道一环、二环或三环法术（由你选择）的法术卷轴 |
| 84-90 | 2 獒犬 |
| 91-96 | 窗户（2尺×4尺，最多2尺深），你可将其布置在一处你能触及的垂直表面上。 |

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:杂货法袍', name: '杂货法袍', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:杂货法袍' }]`（一件物品有好几种次数，就用 '物品次数:杂货法袍:<短名>'）。

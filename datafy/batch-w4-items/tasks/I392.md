# 任务 I392：王者权杖

- 条目键：`XDMG:item:王者权杖`
- 出处：魔法物品（传说，需同调）

## 原文

这把权杖顶端有尖刺状凸起，其可以被用作一把魔法硬头锤。你用此魔法武器进行的攻击检定和伤害掷骰获得+3加值。王者权杖的杖柄上排列着六个不同的按钮，用来启动权杖的相应属性，它还有三个额外词条。词条的描述见下文：
【按钮】
你能够以一个附赠动作按压下列按钮之一。按钮的效应将持续生效，直至你按压另一个按钮或再次按压同一个按钮。再次按压同一个按钮将使权杖变回通常形态。
- 【按钮1】烈焰覆盖的刀刃从权杖凸缘的另一端伸出。火焰发出半径40尺的明亮光照以及额外40尺的微光光照，剑刃可以被用作一柄魔法长剑或短剑（由你选择），命中时额外造成2d6火焰伤害。
- 【按钮2】权杖凸缘头向下折叠，弹出两片月牙状斧刃，这使得权杖变为一柄魔法战斧。你用此魔法武器进行的攻击检定和伤害掷骰获得+3加值。
- 【按钮3】权杖凸缘头向下折叠，杖柄顶端弹出矛尖，杖柄伸长至6尺，将权杖变为一把魔法矛。你用此魔法武器进行的攻击检定和伤害掷骰获得+3加值。
- 【按钮4】权杖将变为一根至多50尺长的爬杆（长度由你指定），但权杖的按钮仍在你触及内。在花岗岩一般坚硬的表面上，爬杆尾部的岩钉和顶部的三个爪钩可以固定住爬杆。爬杆上每隔1尺向侧面伸展出一根3寸长的水平杆，构成一架梯子。爬杆最多可以承受4000磅的重量。如果超重或是失去固定点，则爬杆将会变回权杖。
- 【按钮5】权杖将变为一把手持式攻城锤。用它破坏门、路障或其他障碍时，持用者进行的力量（运动）检定获得+10加值。
- 【按钮 6】权杖将变回或维持通常形态，并指出地磁北极。（如果权杖所在的地点并没有地磁北极的概念，则此功能无效。）权杖还会让你了解到自己在地下的大致深度或在地上的高度。
【汲取生命】
当你以权杖发动的近战攻击命中一名生物时，你可以迫使目标进行一次DC 17的体质豁免。豁免失败则目标额外受到4d6暗蚀伤害，而你恢复等于此暗蚀伤害值一半的生命值。该词条一经使用，直至次日黎明你都无法再次使用。
【麻痹】
当你以权杖发动的近战攻击命中一名生物时，你可以迫使目标进行一次DC 17的体质豁免。豁免失败则目标陷入麻痹状态，持续1分钟。目标在其每回合结束时都可以重新豁免，豁免成功则结束该效应。该词条一经使用，直至次日黎明你都无法再次使用。
【惊骇】
持握此权杖期间，你能够以一个魔法动作迫使位于你30尺内你可见的每名生物进行一次DC 17的感知豁免。豁免失败则目标将陷入恐慌状态，持续1分钟。陷入恐慌状态的目标在其每回合结束时都可以重新豁免，豁免成功则结束其身上的该效应。该词条一经使用，直至次日黎明你都无法再次使用。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:王者权杖', name: '王者权杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:王者权杖' }]`（一件物品有好几种次数，就用 '物品次数:王者权杖:<短名>'）。

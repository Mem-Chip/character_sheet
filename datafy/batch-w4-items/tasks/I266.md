# 任务 I266：念珠项链

- 条目键：`XDMG:item:念珠项链`
- 出处：魔法物品（珍稀，需同调）

## 原文

这条项链挂着1d4 + 2颗由海蓝宝石、黑珍珠或黄玉制成的魔法念珠。项链上同样串有许多由琥珀、血石、黄水晶、珊瑚石、玉石、珍珠或石英石制成的非魔法性的念珠。魔法念珠从项链中取下时将失去其魔法。
项链的每颗魔法念珠都可能是六种念珠之一，由DM决定或在下表中随机掷骰以确定每颗念珠的种类。一条项链可以拥有多颗同种类的念珠。要使用念珠，你必须佩戴着这条项链。每颗念珠容纳着一道法术，你能够以一个附赠动作从中施展它所容纳的法术（需要豁免的法术使用你的法术豁免DC）。一颗魔法念珠中的法术一经施展，那颗念珠直至次日黎明前都无法再次被使用。
| 1d20 | 念珠 | 法术 |
| 1-6 | 祝福之珠 | 祝福术 |
| 7-12 | 疗愈之珠 | 疗伤术（二环版本） |
| 13-16 | 恩赐之珠 | 高等复原术 |
| 17-18 | 打击之珠 | 闪耀斩 |
| 19 | 召唤之珠 | 信仰守卫 |
| 20 | 风行之珠 | 御风而行 |

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:念珠项链', name: '念珠项链', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:念珠项链' }]`（一件物品有好几种次数，就用 '物品次数:念珠项链:<短名>'）。

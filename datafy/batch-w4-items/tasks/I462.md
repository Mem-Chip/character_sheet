# 任务 I462：贤者法杖

- 条目键：`XDMG:item:贤者法杖`
- 出处：魔法物品（传说，需同调）

## 原文

这根法杖具有50充能，可以被用作一把魔法长棍（用这根长棍发动的攻击检定和伤害掷骰获得+2加值）。持握此法杖期间，你进行的法术攻击检定获得+2加值。
【法术吸收】
当你持握此法杖时，你在对抗法术的豁免检定上具有优势。此外，当另一个生物施放一个仅以你为目标的法术时，你可以使用一个反应。如果你这样做，法杖会吸收该法术的魔法，取消其效应，并获得等同于被吸收法术环数的充能。然而，如果这样做导致法杖的总充能数超过50，法杖会爆炸，如同你激活了它的复仇打击（见下文）。
【法术】
持握此法杖期间，你可以从法杖中施展以下表格中的一道法术，使用你自己的法术豁免DC。施展相应法术所需消耗的充能数如下表所示。
| 法术 | 消耗充能 |
| 秘法锁 | 0 |
| 咒唤元素 | 7 |
| 侦测魔法 | 0 |
| 解除魔法 | 3 |
| 变巨/缩小术 | 0 |
| 火球术（7环版本） | 7 |
| 炽焰法球 | 2 |
| 冰风暴 | 4 |
| 隐形术 | 2 |
| 敲击术 | 2 |
| 光亮术 | 0 |
| 闪电束（七环版本） | 7 |
| 法师之手 | 0 |
| 穿墙术 | 5 |
| 位面转移 | 7 |
| 防护善恶 | 0 |
| 心灵遥控 | 5 |
| 火墙术 | 4 |
| 蛛网术 | 2 |
【重获充能】
这根法杖在每日黎明时重获4d6 + 2已消耗的充能。当法杖充能耗尽时，投掷1d20，若结果为20，则此法杖重获1d12 + 1已消耗的充能。
【复仇打击】
你能够以一个魔法动作在自己的膝盖或坚固的表面上折断这把法杖。法杖被摧毁并释放魔力产生一场爆炸，充斥以此法杖为源点的30尺光环 [效应区域]区域。你有50%的概率立刻被传送到某个随机的存在位面以避开爆炸。如果你未能避开效应，你将受到等于16×法杖充能的力场伤害。区域内的每个其他生物必须进行一次DC 17的敏捷豁免。失败则受到等于6×法杖充能的力场伤害。成功则伤害减半。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:贤者法杖`：贤者法杖（充能 50）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 50 发充能：花充能写 `cost: [{ resource: '物品充能:贤者法杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:贤者法杖', name: '贤者法杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:贤者法杖' }]`（一件物品有好几种次数，就用 '物品次数:贤者法杖:<短名>'）。

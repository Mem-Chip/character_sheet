# 任务 I123：漂浮之球

- 条目键：`XDMG:item:漂浮之球`
- 出处：魔法物品（非普通）

## 原文

这个厚玻璃制成的小球重1磅。在它周围60尺内，你可以说出命令语以使它发出相当于法术光亮术或 昼明术的光芒。使用一次后直至次日黎明前，昼明术效应将无法再次使用。
你可以用魔法动作来说出另一个命令语，以让发光球体飞到空中，漂浮在离地面不超过5尺的地方。球体将持续漂浮在空中，直到你或另一生物将它抓住。如果你离开球体周围60尺范围，则它将沿最短路径跟随你移动直到距离你60尺为止。如果它的移动遭到妨碍，它将闪烁着落回地面并回到启动前的状态，其发出的光芒也会熄灭。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:漂浮之球', name: '漂浮之球', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:漂浮之球' }]`（一件物品有好几种次数，就用 '物品次数:漂浮之球:<短名>'）。

# 任务 I082：重生坩埚

- 条目键：`XDMG:item:重生坩埚`
- 出处：魔法物品（非常珍稀，需同调）

## 原文

这只微型小锅的铸铁侧边上刻有英雄群像的浮雕。
你可以将这件坩埚作为法器使用，且其可以作为法术探知术的代替材料。
【酿造药水】
当你完成一次长休时，你可以使用坩埚制造一瓶高等治疗药水 ，这需要花费你1分钟的时间。药水持续24个小时，若其没有被使用，则它失去魔力。
【死者复活】
以一个魔法动作，你可以让坩埚增大至足以容纳一个中型生物。你也可以用一个魔法动作让坩埚恢复其普通大小，并且无害地将任何它无法容纳的东西转出到最近未被占据的位置。
如果你将一个类人生物的尸体放入坩埚之中并将200磅的盐（耗费10金币）掩埋尸体持续八小时，那么盐会被消耗，而那个生物会在下一个黎明时复活，如同法术死者复活。使用后七日之内，坩埚的此项词条都无法再次使用。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:重生坩埚', name: '重生坩埚', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:重生坩埚' }]`（一件物品有好几种次数，就用 '物品次数:重生坩埚:<短名>'）。

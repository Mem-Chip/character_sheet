# 任务 I494：指挥魔杖

- 条目键：`XDMG:item:指挥魔杖`
- 出处：魔法物品（普通）

## 原文

这根魔杖具有3充能。持握它时，你可以执行魔法动作并消耗1充能，通过挥舞它来创造一段管弦乐。这段音乐在120尺之内都能被听到，并且在你停止挥舞魔杖时结束。
【重获充能】
这根魔杖在每日黎明时重获所有已消耗的充能。当充能数耗尽时，骰一次1d20。如果骰值为1，魔杖将在悲伤的低音号声中化作飞灰并被摧毁。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:指挥魔杖`：指挥魔杖（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:指挥魔杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:指挥魔杖', name: '指挥魔杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:指挥魔杖' }]`（一件物品有好几种次数，就用 '物品次数:指挥魔杖:<短名>'）。

# 任务 I448：湮灭法球

- 条目键：`XDMG:item:湮灭法球`
- 出处：魔法物品（传说）

## 原文

这个直径2尺的黑色球体是多元宇宙中的一个空洞，它悬浮在空间中，由一个围绕在它周围的魔法场维持稳定。
湮灭法球会毁灭任何穿过它或被它穿过的事物，只有神器例外：除非某件神器的弱点正是湮灭法球，否则神器均可以不受影响地穿过法球。任何触碰到法球但未被完全吞没或毁灭的东西将受到8d10力场伤害。
【控制法球】
湮灭法球总是保持静止，除非受到人控制。如果你位于法球60尺内，你能够以一个魔法动作进行一次DC 25的智力（奥秘）检定。成功则你控制法球直至你的下个回合开始，若法球已处于一名其他生物的控制之下，则该生物失去控制权。失败则法球向你直线移动10尺。
控制法球期间，你能够以一个附赠动作令法球向一个你选择的方向移动一定尺数，具体尺数等于5×你的智力调整值（至少5尺）。法球进入一名生物的占据空间时，该生物必须成功通过一次DC 19的敏捷豁免，否则将触碰到法球，受到8d10力场伤害。因受此伤害而生命值降至0的生物将被毁灭，它携带的财物将留在原地，尸体则灰飞烟灭。
【法球碰撞】
如果湮灭法球与位面传送门（如异界之门制造的传送门）或是异位面空间（如次元洞内部）接触，则由DM根据下表随机决定发生的事件：
| 1d100 | 结果 |
| 01-50 | 法球被摧毁了。 |
| 51-85 | 法球穿过位面传送门或进入异位面空间 |
| 86-00 | 一个空间裂缝出现，将湮灭法球和位于其180尺内的所有生物和物件送到一个随机存在位面。 |

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品:湮灭法球`：湮灭法球（数量）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:湮灭法球' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:湮灭法球', name: '湮灭法球', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:湮灭法球' }]`（一件物品有好几种次数，就用 '物品次数:湮灭法球:<短名>'）。

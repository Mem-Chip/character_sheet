# 任务 I336：假肢

- 条目键：`XDMG:item:假肢`
- 出处：魔法物品（普通）

## 原文

这件魔法物品能替代一处缺失的肢体——一只手，一条手臂，一条腿，或是类似的身体部位。在假肢已完成安装期间，它能像被代替的肢体一样正常工作。你可以用一个魔法动作将其装好或者卸除，且只要你活着，它就不能在你非自愿的情况下被移除。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:假肢', name: '假肢', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:假肢' }]`（一件物品有好几种次数，就用 '物品次数:假肢:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

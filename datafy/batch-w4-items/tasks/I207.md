# 任务 I207：幻象乐器

- 条目键：`XDMG:item:幻象乐器`
- 出处：魔法物品（普通）

## 原文

在你使用这把乐器进行演奏期间，你可以使用一个魔法动作在以乐器为源点的5尺光环 [效应区域]内创造出无害的、幻象般的视觉效应。如果你是一名吟游诗人，则光环 [效应区域]的范围将提升至15尺。简单的视觉效应包括了幻光的音符、虚幻的舞者、舞动的蝴蝶、以及飘散的雪花。这种魔法效应既无触感亦无声音，且它们显然是幻象。你终止演奏的同时，此效应结束。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:幻象乐器', name: '幻象乐器', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:幻象乐器' }]`（一件物品有好几种次数，就用 '物品次数:幻象乐器:<短名>'）。

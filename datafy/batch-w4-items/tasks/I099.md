# 任务 I099：发条护符

- 条目键：`XDMG:item:发条护符`
- 出处：魔法物品（普通）

## 原文

这枚铜制的护符内有数个互相咬合的微小齿轮，其以机械境——一个秩序至极，万物皆可被机械预测的位面——的魔法所驱动。模糊的滴答声与呼呼的噪音从中传出。佩戴该护符期间，当你进行一次攻击检定时，你可以放弃掷骰并在d20的骰值上取10。该词条一经使用，直至次日黎明前都无法再次使用。
佩戴着这个护身符期间，当你进行一次攻击检定时，你可以放弃掷骰并在d20的骰值上取10。使用后，直到下一个黎明前此物品的此能力无法被再次使用。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:发条护符`：发条护符（充能 1）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 1 发充能：花充能写 `cost: [{ resource: '物品充能:发条护符', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:发条护符', name: '发条护符', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:发条护符' }]`（一件物品有好几种次数，就用 '物品次数:发条护符:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

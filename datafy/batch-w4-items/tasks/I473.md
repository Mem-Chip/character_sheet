# 任务 I473：纯善护符

- 条目键：`XDMG:item:纯善护符`
- 出处：魔法物品（传说，需同调）

## 原文

这枚护符是良善的象征。触碰护符的亡灵或邪魔生物将受到8d6光耀伤害，每当该生物持握或携带此护符结束其回合时，将再次受到此伤害。
【圣徽】
你可以将护符当作圣徽使用。着装或持握护符期间，你进行的法术攻击检定获得+2加值。
【至纯审判】
护符具有7充能。着装或持握护符期间，你能够以一个魔法动作，消耗1充能并以一名位于你120尺内的地面上的你可见的生物为目标，使目标脚下张开一道火焰裂隙。目标必须进行一次DC 20的敏捷豁免，若目标是邪魔或亡灵，其进行此豁免具有劣势。豁免失败则目标坠入裂隙，灰飞烟灭；成功则目标不会坠入裂隙，但因审判受到4d6心灵伤害。无论情况如何，裂隙随后将不留痕迹地闭合。充能耗尽时，护符将被摧毁，化为闪耀金光的尘埃。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品:纯善护符`：纯善护符（数量）
- `物品充能:纯善护符`：纯善护符（充能 7）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:纯善护符' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 有 7 发充能：花充能写 `cost: [{ resource: '物品充能:纯善护符', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:纯善护符', name: '纯善护符', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:纯善护符' }]`（一件物品有好几种次数，就用 '物品次数:纯善护符:<短名>'）。

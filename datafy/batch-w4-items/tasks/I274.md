# 任务 I274：龙珠

- 条目键：`XDMG:item:龙珠`
- 出处：魔法物品（神器，需同调）

## 原文

很久以前，在龙枪的设定中，精灵与人类对色彩巨龙发动了一场惨烈的战争。在最后世界接近崩溃之际，大法师诸塔的法师们齐聚一堂，铸造了五颗龙珠来帮助击败巨龙。五颗龙珠分给了五座法师塔，他们凭借龙珠的力量克敌制胜。法师们用龙珠引诱龙族，然后以强大的法术轰杀之。
随着大法师诸塔在后来的年代中倒塌，其持有的五颗龙珠也相继被摧毁或遗失在传说之中。相传仍然有三颗保存完好的龙珠流传在世。虽然它们的魔法在几个世纪中被扭曲变换，但其呼唤巨龙的原始功能却依然健全，还能在一定程度上控制龙族。
每颗龙珠内都包含着一条邪恶巨龙的精神，对任何尝试从中引出魔法的企图怀有愤恨。那些试图使用龙珠但意志不坚定的人有时会发现自身实为被龙珠所蛊惑。
龙珠是一枚直径约10寸的蚀刻水晶球。使用时，其直径增长至20寸，并且在内部萦绕着迷雾。
与龙珠维持同调期间，你能够以魔法动作窥视龙珠深处。然后你必须进行一次DC 15的魅力豁免。若豁免成功，你将可以控制龙珠直至同调中断。若豁免失败，你将被龙珠魅惑直至同调中断。
被龙珠魅惑期间，你不能自行中断同调，而龙珠可以对你随意施展暗示术（豁免DC 18），并蛊惑你助推其邪恶目标。龙珠里的巨龙精神有着各种需求：歼灭某个特定社团或组织；从龙珠中解放；四处折磨世人；传播提亚马特信仰，或是由DM决定的其他事情。

【法术】
龙珠具有7充能，并在每日黎明时重获1d4 + 3已消耗的充能。你能以龙珠施展下表中的法术（豁免DC18）。表中表明了你施展对应的法术需要消耗多少充能。
| 法术 | 消耗充能 |
| 疗伤术（9环版本） | 4 |
| 昼明术 | 1 |
| 防死结界 | 2 |
| 侦测魔法 | 0 |
| 探知术（豁免DC 18） | 3 |
【呼唤巨龙】
控制龙珠期间，你能够以魔法动作令龙珠发出心灵感应呼唤，此呼唤向所有方向延伸40英里。范围内的色彩龙族将被迫以最直接的路线尽可能快的来到龙珠处。龙族神祇（如提亚马特）不受此呼唤影响。被龙珠唤来的色彩龙族可能因其非自愿的到来与你敌对【态度】。该词条一经使用，一小时内你都无法再次使用。
【摧毁此珠】
龙珠的AC为20，当其受到+3魔法武器或法术解离术的伤害时，龙珠被摧毁。其余任何事物都无法摧毁龙珠。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 7 发充能：花充能写 `cost: [{ resource: '物品充能:龙珠', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:龙珠', name: '龙珠', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:龙珠' }]`（一件物品有好几种次数，就用 '物品次数:龙珠:<短名>'）。

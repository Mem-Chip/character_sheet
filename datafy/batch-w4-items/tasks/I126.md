# 任务 I126：干燥粉

- 条目键：`XDMG:item:干燥粉`
- 出处：魔法物品（非普通）

## 原文

这个小包里共装着1d6 + 4把粉末。你可以用一个操作动作将一把粉末洒到水面上。粉末将把15尺立方 [效应区域]的水变成一个弹珠大小的小球，漂浮或停止在粉末被洒下的位置附近。小球的重量可以忽略不计。 生物可以用操作动作将小球摔在某个结实表面，以令小球破碎并释放其中的水分。这样做会摧毁小球并使其失去其魔力。
你可以用操作动作将一把粉末洒在5尺内一个身体大部分由水组成的元素生物（例如水元素或水诡 ）身上。此时该生物须进行一次DC 13的体质豁免，豁免失败者受到10d6点暗蚀伤害，豁免成功则伤害减半。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:干燥粉', name: '干燥粉', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:干燥粉' }]`（一件物品有好几种次数，就用 '物品次数:干燥粉:<短名>'）。

# 任务 I474：法球护符

- 条目键：`XDMG:item:法球护符`
- 出处：魔法物品（传说，需同调）

## 原文

持握或着装此护符期间，你为操控湮灭法球而进行的智力（奥秘）检定具有优势。此外，你的回合开始时，若你正在操控湮灭法球，你能够以一个魔法动作将法球移动一定尺数，具体尺数等于10+10×你的智力调整值。以此法移动法球时，其不必以直线进行运动。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:法球护符', name: '法球护符', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:法球护符' }]`（一件物品有好几种次数，就用 '物品次数:法球护符:<短名>'）。

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

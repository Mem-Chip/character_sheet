# 任务 I291：次元洞

- 条目键：`XDMG:item:次元洞`
- 出处：魔法物品（珍稀）

## 原文

这块如丝绸般顺滑的精致黑色布料，折叠起来只有手帕大小。布料展开后为直径6尺的圆形盖布。
你可以使用一个魔法动作展开次元洞，并将其放置在或靠着一处坚固表面。次元洞会随即打开一个10尺深的异次元孔洞。次元洞内的圆柱形空间存在于异位面，因此无法用于创造开放通道。任何位于一个打开的次元洞内的生物都可以通过攀爬从洞口离开。
你可以使用一个魔法动作通过抓住布料的边缘将其折叠起来以关闭次元洞。折叠布料会关闭洞口，里面的任何生物或物件都会留在异次元空间中。无论内部装了什么，次元洞的重量都可以忽略不计。
如果次元洞被折叠起来，一个位于洞内异次元空间的生物可以使用一个动作进行一次DC 10的力量（运动）检定。如果检定成功，该生物就会强行离开，并出现在次元洞周边5尺范围内。一个关闭的次元洞可容纳足够呼吸1小时的空气，除以洞内呼吸生物的数量。
将次元洞放入次元袋、霍华德便利袋或其他类似物品产生的异次元空间时，将立即摧毁这两件物品并打开一扇通往星光位面Astral Plane的门扉。门扉会产生在被放入另一件物品的前一件物品所在的空间位置。任何在门扉周边10尺范围内且不在掩护之后的生物将被吸入门内并送到星光位面的随机位置，随后该门关闭。这扇门扉只能单向通过且无法被再次打开。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:次元洞', name: '次元洞', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:次元洞' }]`（一件物品有好几种次数，就用 '物品次数:次元洞:<短名>'）。

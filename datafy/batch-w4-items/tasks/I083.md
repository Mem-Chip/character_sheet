# 任务 I083：命令气元素香炉

- 条目键：`XDMG:item:命令气元素香炉`
- 出处：魔法物品（珍稀）

## 原文

当你轻轻挥动这件香炉期间，你可以用一个魔法动作来召唤一只气元素。气元素会出现在距离香炉最近的未被占据的空间、理解你所说的语言、服从你的命令、使用你的先攻并在你之后立即执行其回合。气元素会在1小时后、或它死亡时、或你用一个附赠动作解消时消失。直到次日黎明前，香炉都无法再以该方式进行使用。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:命令气元素香炉', name: '命令气元素香炉', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:命令气元素香炉' }]`（一件物品有好几种次数，就用 '物品次数:命令气元素香炉:<短名>'）。

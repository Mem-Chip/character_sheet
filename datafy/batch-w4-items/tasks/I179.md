# 任务 I179：鬼婆之眼

- 条目键：`XDMG:item:鬼婆之眼`
- 出处：魔法物品（非普通）

## 原文

一颗鬼婆之眼具有3充能。你佩戴或持握这件物品期间可以消耗1充能以施展法术黑暗视觉（只能以自身为目标）或识破隐形。鬼婆之眼在每日黎明时恢复全部已消耗的充能。
【集会传感器】
鬼婆之眼通常会被托付给鬼婆的仆从以对其进行保护与转移。隶属于创造该鬼婆之眼集会的鬼婆若与鬼婆之眼处于同一存在位面上，则其可以用一个魔法动作透过鬼婆之眼视物。只要该鬼婆维持专注，则该效应将会一直持续。同一集会中的多个鬼婆可以同时透过该鬼婆之眼视物。
【创造鬼婆之眼】
只有鬼婆集会才能够制造此物品，其成品由裹在清漆中的真实眼球制成，并通常镶在吊坠或其他可佩戴的物品之上。一个鬼婆集会在同一时间只能拥有一颗鬼婆之眼，制作一个新的则需全部三位集会成员进行一场特殊仪式。这场仪式耗时1小时，且若一名或多名鬼婆陷入失能状态，则仪式无法进行。若鬼婆们在仪式期间执行任何其他动作，则仪式失败并终止。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:鬼婆之眼`：鬼婆之眼（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:鬼婆之眼', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:鬼婆之眼', name: '鬼婆之眼', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:鬼婆之眼' }]`（一件物品有好几种次数，就用 '物品次数:鬼婆之眼:<短名>'）。

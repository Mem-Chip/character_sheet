# 任务 I466：凋零法杖

- 条目键：`XDMG:item:凋零法杖`
- 出处：魔法物品（珍稀，需同调）

## 原文

该法杖有3发充能，且每天黎明时恢复1d3发已消耗的充能。
这把法杖可作为一把魔法长棍使用。命中时，它造成与普通长棍相同的伤害，并且你可以消耗1发充能以对目标额外造成2d10点暗蚀伤害，并迫使其进行一次DC 15的体质豁免检定。豁免失败时，目标在1小时内，任何使用力量或体质的属性检定或豁免检定具有劣势。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品充能:凋零法杖`：凋零法杖（充能 3）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 3 发充能：花充能写 `cost: [{ resource: '物品充能:凋零法杖', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:凋零法杖', name: '凋零法杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:凋零法杖' }]`（一件物品有好几种次数，就用 '物品次数:凋零法杖:<短名>'）。

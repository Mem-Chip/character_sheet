# 任务 I076：水下呼吸帽

- 条目键：`XDMG:item:水下呼吸帽`
- 出处：魔法物品（非普通）

## 原文

着装此帽期间，你可以在水下用一个魔法动作让它在你头部周围创造出一个空气泡，它可以供你在水下正常呼吸。空气泡将持续存在，并在你摘掉帽子或离开水下时结束。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:水下呼吸帽', name: '水下呼吸帽', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:水下呼吸帽' }]`（一件物品有好几种次数，就用 '物品次数:水下呼吸帽:<短名>'）。

## 接口

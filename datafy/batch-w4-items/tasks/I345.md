# 任务 I345：艾罗娜的箭袋

- 条目键：`XDMG:item:艾罗娜的箭袋`
- 出处：魔法物品（非普通）

## 原文

这个箭袋有三个大小不一的隔层，每个隔层都连接着一个异次元空间。无论其中存放着多少东西，箭袋的总重量都永远都不会超过2磅。最小的隔层可以容纳至多60支箭、弩矢或类似的物件；中等大小的隔层可以容纳至多18支标枪或类似的物件；最大的隔层可以容纳至多6件长条型的物件，例如弓、长棍、矛等。
你可以如同从普通的箭袋或剑鞘中抽出物品一般抽出艾罗娜箭袋中的物品。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:艾罗娜的箭袋', name: '艾罗娜的箭袋', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:艾罗娜的箭袋' }]`（一件物品有好几种次数，就用 '物品次数:艾罗娜的箭袋:<短名>'）。

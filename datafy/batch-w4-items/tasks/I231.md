# 任务 I231：收妖瓶

- 条目键：`XDMG:item:收妖瓶`
- 出处：魔法物品（传说）

## 原文

持握这个带着黄铜瓶塞的铁瓶期间，你能够以一个魔法动作，指定一名位于你60尺内，你可见的生物为目标。若瓶子是空的，且目标来自你正所处的存在位面以外的位面，则目标必须成功通过一次DC 17的感知豁免，否则将被困入瓶中。如果目标先前曾经被困入瓶中过，则它进行该豁免时具有优势。一旦被瓶子困住，该生物将留在瓶中，直至被释放。收妖瓶同时只能容纳最多一名生物。困在瓶中的生物不再衰老，也不需要呼吸、进食或饮水。
你能够以一个魔法动作拔掉瓶塞释放瓶中的生物。然后该生物将服从你的命令，持续1小时，即使该生物不懂得你下达命令时使用的语言，它也能听懂你的命令。如果你没有下达命令或你的命令可能导致该生物死亡或被囚禁，则它除自卫外不会执行任何动作。持续时间结束后，该生物将按其正常的性格和阵营行动。
法术鉴定术可以辨别瓶中是否有囚禁生物，但只有打开瓶塞才能确定其中的生物具体是什么。一个新发现的收妖瓶可能已经囚禁了一名由DM决定或根据下表随机决定的生物（以下生物的数据见怪物图鉴）。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:收妖瓶', name: '收妖瓶', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:收妖瓶' }]`（一件物品有好几种次数，就用 '物品次数:收妖瓶:<短名>'）。

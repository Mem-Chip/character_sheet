# 任务 I481：火绒盒

- 条目键：`XPHB:item:火绒盒`
- 出处：冒险装备

## 原文

火绒盒是一种装有打火石、火镰和火绒（通常是浸泡在燃油里的干布料）的小型容器，其中的物品可以用来点火。你可以使用附赠动作来用它点燃任何具有燃料的东西——例如蜡烛、油灯、附盖提灯或火把。在没有燃料的情况下生火需要1分钟时间。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:火绒盒', name: '火绒盒', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:火绒盒' }]`（一件物品有好几种次数，就用 '物品次数:火绒盒:<短名>'）。

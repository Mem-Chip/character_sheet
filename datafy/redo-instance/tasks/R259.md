# 任务 R259：无踪粉

- 条目键：`XDMG:item:无踪粉`
- 出处：魔法物品（非普通）

## 原文

这些粉末形同细沙，其分量足够使用一次。你可以用操作动作将粉末洒向空中，让你和以你为源点的10尺光环 [效应区域]内的每个生物和物件变为隐形状态2d4分钟。每个目标的隐形时长相同，一旦粉末的魔法生效，其即被消耗。如果一名受影响的生物发动攻击或者施展法术，则该生物的隐形效应也随之终止。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `物品:无踪粉`：无踪粉（数量）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:无踪粉' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值、属性定值、伤害抗性 / 免疫、固定的速度，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:无踪粉', name: '无踪粉', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:无踪粉' }]`（一件物品有好几种次数，就用 '物品次数:无踪粉:<短名>'）。

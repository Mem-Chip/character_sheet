# 任务 R238：加速药水

- 条目键：`XDMG:item:加速药水`
- 出处：魔法物品（非常珍稀）

## 原文

当你饮下这瓶药水时，你获得法术加速术的效应，持续1分钟（无需专注），并且不会遭受通常在效应结束时泛起倦意的影响。
这瓶药水里黄黑相间的流体正自行旋转成漩涡状。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:加速药水' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值、属性定值、伤害抗性 / 免疫、固定的速度，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:加速药水', name: '加速药水', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:加速药水' }]`（一件物品有好几种次数，就用 '物品次数:加速药水:<短名>'）。

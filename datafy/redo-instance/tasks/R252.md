# 任务 R252：统御权杖

- 条目键：`XDMG:item:统御权杖`
- 出处：魔法物品（珍稀，需同调）

## 原文

你可以执行魔法动作来展示这根权杖，并向你可见的，周身120尺内你所指定的每个生物下令服从于你。每个目标必须通过一次DC 15的感知豁免，否则陷入魅惑状态8小时。在以这种方式被魅惑期间，生物将视你为值得托付信赖的领袖。如果你或你的盟友伤害了目标，或命令目标去做违反其天性的行为时，以此法造成的魅惑将终止。该词条一经使用，直至次日黎明前你都无法再次使用。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值、属性定值、伤害抗性 / 免疫、固定的速度，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:统御权杖', name: '统御权杖', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:统御权杖' }]`（一件物品有好几种次数，就用 '物品次数:统御权杖:<短名>'）。

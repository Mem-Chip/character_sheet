# 任务 R256：维克那法眼

- 条目键：`XDMG:item:维克那法眼`
- 出处：魔法物品（神器，需同调）

## 原文

维克那是一名强大的法师。他行使魔法之力征讨，建立了一个恐怖的大帝国。然而，拥有强大力量的维克依然畏惧死亡，他采取手段，通过成为巫妖阻拦死亡的脚步。
一名名为凯斯的将军发动了叛乱，并在一场骇人的战争中结束了维克那的统治，维克那剩下的只有一只手掌和一只眼睛，这些可怖的神器仍试图在世上贯彻维克纳的意志。
维克那法眼Eye of Vecna和维克那魔掌是独立的神器，可能一起出现也可能被分开发现。法眼布满血丝，有如刚刚直接从眼眶中抽出。魔掌则是风干萎缩的左肢。
【法眼与魔掌的随机词条】
维克纳法眼具有下列随机词条：
- 1项神器词条; 次要增益词条词条
- 1项神器词条; 主要增益词条词条
- 1项神器词条; 次要减益词条词条
【同调法眼】
要与法眼进行同调，你必须将其压入挖空的眼眶内，法眼会自行嫁接入你的头部并留在其位置直至你死亡。此后法眼一旦被取下，你将立即死亡。
【法眼词条】
与法眼维持同调期间，你的阵营为中立邪恶，且你获得以下增益：
- 【真实视觉】你具有240尺的真实视觉。
- 【施法】法眼具有8充能，并在每日黎明时重获1d4 + 4已消耗的充能。你能以法眼施展维克纳法眼法术表中的法术（豁免DC 18）。表中表明了你施展对应的法术需要消耗多少充能。每当你以法眼施展法术时，维克纳有5%的概率撕裂你的灵魂并将之吞噬，然后如控制傀儡一般控制你的躯体。这种情况下，你成为DM控制的NPC。 【维克那法眼法术】 | 法术 | 消耗充能 | | 鹰眼术 | 2 | | 疯狂冠冕 | 1 | | 解离术 | 4 | | 支配怪物 | 5 | | 摄心目光 | 4 |
- 【X光视野】你能够以魔法动作获得距离30尺的X光视野，持续1分钟。对你而言，此视觉范围内的实体均为透明状态，并且不会阻碍光线通过。此视觉可以穿透1尺厚的石头、1寸厚的普通金属、或是至多3尺厚的木头或泥土。更厚的物件，或是一层铅片，将阻碍这种视觉。
【摧毁法眼和魔掌】
如果维克那法眼和维克那魔掌与同一生物维持同调，并且该生物被凯斯之剑斩杀，则法眼和魔掌即时迸出火焰烧成灰烬，并且被摧毁。任何其他摧毁法眼和魔掌的尝试似乎也是可行的，但这些神器会在维克那的其中一个隐藏宝库中重现，等着再临人间。

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 8 发充能：花充能写 `cost: [{ resource: '物品充能:维克那法眼', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值、属性定值、伤害抗性 / 免疫、固定的速度，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:维克那法眼', name: '维克那法眼', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:维克那法眼' }]`（一件物品有好几种次数，就用 '物品次数:维克那法眼:<短名>'）。

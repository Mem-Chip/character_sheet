# 任务 R040：死灵魔典

- 条目键：`AU:法师:死灵魔典:3`
- 出处：法师 3 级（死灵师，AU）

## 原文

记载在你的法术书中的死灵魔法秘仪令你获得了更多的力量。你获得以下增益：
【暗蚀抗性】
你获得对暗蚀伤害的抗性。
【亡灵魔宠】
法术寻获魔宠出现在你的法术书中。当你施展该法术时，除了通常的形态选项，你还可以改为选择下列特殊形态之一：骷髅或丧尸（魔宠的数据卡见玩家手册的附录B）。当你使用通常的形态选项时，你可以选择亡灵作为其生物类型。
此外，当你执行攻击动作时可以放弃自己动作攻击中的一次攻击，转而让你的魔宠使用其反应发动一次攻击。
【亡灵生机】
当你使用法术位施展一道死灵法术时，你可以选择60尺范围内一名你可见的亡灵，使其恢复等同于所消耗法术位环阶加你的法师等级的生命值。

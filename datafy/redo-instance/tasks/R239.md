# 任务 R239：劲敌硬币

- 条目键：`XDMG:item:劲敌硬币`
- 出处：魔法物品（普通）

## 原文

这枚金币的两面均饰有一个生物的浮雕。这两个被描绘的生物必须为彼此知名的对手或敌人。例如，一枚劲敌硬币的一面可能是伊格薇尔伏，而另一面是魔邓肯；或者一面是温戈尔，另一面是提亚马特。其中一个人物在硬币的正面，另一个在反面。
这枚硬币具有1充能，并在每日黎明时重获已消耗的充能。你可以使用一个魔法动作抛掷这枚硬币，并消耗其充能。掷一枚任意骰子来确定硬币是正面朝上（若结果为偶数）还是反面朝上（若结果为奇数）。此结果决定了硬币产生的效应：
- 【正面】以位于你60尺内一个你可见的生物为目标。目标进行一次DC 13的感知豁免：如果豁免失败，目标会受到2d4心灵伤害，并在其下一回合结束前进行的下一次攻击检定中具有劣势；豁免成功则目标仅受半伤。
- 【背面】你受到1d4心灵伤害。

## 可以花的资源（cost 里的 resource 只能用这些 id）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 有 1 发充能：花充能写 `cost: [{ resource: '物品充能:劲敌硬币', n: <几发> }]`。充能怎么恢复（黎明）由长休处理，**不要**自己声明 resources。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值、属性定值、伤害抗性 / 免疫、固定的速度，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:劲敌硬币', name: '劲敌硬币', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:劲敌硬币' }]`（一件物品有好几种次数，就用 '物品次数:劲敌硬币:<短名>'）。

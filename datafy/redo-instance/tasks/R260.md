# 任务 R260：吸矢盾

- 条目键：`XDMG:item:吸矢盾`
- 出处：魔法物品（珍稀，需同调）

## 原文

持握此盾牌期间，你对抗远程攻击的护甲等级具有+2加值。该加值将加在盾牌通常提供的加值上。
此外，当一个攻击者对你周围5尺内的目标发动远程攻击时，你可以执行反应以替代该目标成为此次攻击的目标。

# 任务 R273：基础毒药

- 条目键：`XPHB:item:基础毒药`
- 出处：冒险装备

## 原文

以一个附赠动作，你可以将一小瓶基础毒药涂抹在一把武器或至多三枚弹药上。当一个生物受到由涂过毒的武器或弹药所造成的穿刺或劈砍伤害时，该生物将受到额外1d4点毒素伤害。毒药一旦被涂抹，毒效只会持续1分钟或直至造成了额外伤害。

## 可以花的资源（cost 里的 resource 只能用这些 id）

## 补充

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:基础毒药' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值、属性定值、伤害抗性 / 免疫、固定的速度，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。
- 「消耗 1 发充能施展火球术」这类：写成动作，root 里照那个法术的效果写（DC 用物品写的数值，没写就用 self.spell.dc）。
- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:基础毒药', name: '基础毒药', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:基础毒药' }]`（一件物品有好几种次数，就用 '物品次数:基础毒药:<短名>'）。

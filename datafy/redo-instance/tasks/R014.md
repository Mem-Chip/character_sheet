# 任务 R014：混乱箭

- 条目键：`XGE:spell:混乱箭`
- 出处：1 环法术
- 1 环；施法时间：1 动作；距离：120 尺；持续时间：立即

## 原文

你向着施法距离内的一个生物掷出一团变化不定、高声尖鸣的混乱能量。对目标进行一次远程法术攻击。击中时，目标受到2d8 + 1d6点伤害。选择一颗d8投出的数字来决定它的伤害类型，投出的数字与对应的类别见下表。
【混乱箭】
| d8 | 伤害类型 |
|  | 强酸 |
|  | 寒冷 |
|  | 火焰 |
|  | 力场 |
|  | 闪电 |
|  | 毒素 |
|  | 心灵 |
|  | 雷鸣 |
若你的两颗d8投出了相同的数字，混乱能量将从目标跳跃到一个由你选择的、处于它周围 30 尺内的其他生物上。对新目标进行一次新的攻击检定，进行新的伤害掷骰，这次伤害掷骰也可能令混沌能量跳跃。
一个生物只能被此混乱箭选作目标一次。

## 升环

【升环施法】
当你使用二环或更高的法术位施展此法术时，每个生物受到额外伤害，类型与投出的一致。额外伤害等于高于一环的每个等级1d6点。

## 这次为什么重做

- 命中根据两颗d8掷骰决定伤害类型，若两颗点数相同则跳跃对新目标发起重复攻击（repeat）

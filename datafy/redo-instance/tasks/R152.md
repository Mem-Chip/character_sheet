# 任务 R152：蜂聚集群

- 条目键：`TCE:游侠:蜂聚集群:3`
- 出处：游侠 3 级（集群守卫，TCE）

## 原文

3级集群牧者特性
无形自然精魂形成的集群与你形影不离并会在战斗中对你施以援手。直到你死亡为止，集群会存在于你的空间中，在你身上爬行或在你周身的空间里飞舞或窜动。你自行决定集群的外观，或者你投掷集群外观表格来决定其外观。
【集群外观】
| d4 | 外貌 |
| 1 | 群聚的昆虫 |
| 2 | 微小的枯枝怪 |
| 3 | 飞舞的群鸟 |
| 4 | 好动的皮克精 |
每个你的回合一次，当你的攻击命中一个生物后，你能立刻让集群以以下一种方式助你一臂之力：
- 集群对这次攻击的目标造成1d6点穿刺伤害。
- 这次攻击的目标必须成功通过对抗你法术豁免DC的力量豁免检定，豁免失败将被集群水平移动最多15尺，方向由你选择。
- 你被集群水平移动5尺，方向由你选择。
【你的集群】
一位集群守卫的集群和法术反应了角色与自然精魂的联系。在游戏中，多抓住机会来描述你自己的集群和游侠法术。比方说，当你的游侠施展气化形体时，施法对象可能会消失在他自己的集群中，而非变为一团雾气，而秘法眼则可以创造出一部分分离的集群为你进行侦查。这样的描述不会改变法术的效应，但它们能让通过特性描述自己的角色更加引人入胜。需要更多个性化法术的指导，请见第三章中的"定制法术"一节。
同样，记住你的集群外表能由你自己定制，别局限于单一的造型。也许精魂的外表会随着游侠的情绪而千变万化，或者随着季节而呈现出不同的形象。这一切都由你自己选择。

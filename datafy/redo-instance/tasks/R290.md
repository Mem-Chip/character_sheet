# 任务 R290：魔化武器

- 条目键：`XPHB:spell:魔化武器`
- 出处：2 环法术
- 2 环；施法时间：1 附赠动作；距离：触及；持续时间：1 小时

## 原文

你触碰一件非魔法武器。直到法术结束前，它成为魔法武器且在进行攻击检定和伤害掷骰时具有 +1 加值。你再次施展该法术时，先前的效应提前结束。

## 升环

【升环施法】
使用三至五环的法术位时，此法术的加值增加至 +2；使用高于五环的法术位时，此法术的加值增加至 +3。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 接口（别处按这些名字调用，必须一致）

- 动作：id `cast`，name「魔化武器」
- 效应名：「魔化武器」

## 这次为什么重做

- 赋予非魔法武器攻击与伤害加值，需在武器攻击与伤害时读取具体武器判断是否受加持，卡在装备槽位系统
- 审查时记下要读：action.attack.weapon
- 挂在：rollMod:attack,rollMod:damage
- 另外还卡在：item（这部分做不到就照旧写进 text，automation 标 partial）

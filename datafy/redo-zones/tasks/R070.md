# 任务 R070：滑溜之油

- 条目键：`XDMG:item:滑溜之油`
- 出处：魔法物品（非普通）

## 原文

一扁瓶的滑溜之油可以覆盖住连带着其着装与携带的装备的一个中型或小型生物（生物体型每比中型大一级，就需要多用一扁瓶）。抹上油需要花费10分钟。被影响的生物将会获得行动自如法术的效应，持续8小时。
此外，以一个魔法动作，油可以被泼到地面上并覆盖10尺方形区域，并在此区域内复现出油腻术法术的效应，持续8小时。
这种粘稠的黑色油膏浑浊且厚重，但在被倒出来时却又流动迅速。

- 物品的条目在**装备着**（需要同调的还要已同调）时生效；消耗品带在身上就能用。
- 这是消耗品：用一次的动作写 `cost: [{ resource: '物品:滑溜之油' }]`（数量引擎自己管）。喝药水是附赠动作（activation: 'bonus'）；投掷类（炼金火、圣水、强酸瓶）是一次攻击或豁免。
- 护甲、武器的 +N 和 AC / 豁免 / 法术攻击 / 法术 DC 的固定加值、属性定值、伤害抗性 / 免疫、固定的速度，人物卡已经算了（只要物品数据里有），**不要**再写 —— 只有这些的物品直接跳过。

- 「长休（或黎明）前只能用一次」这类没有充能的次数：在条目顶层声明 `resources: [{ id: '物品次数:滑溜之油', name: '滑溜之油', formula: 1, recovery: 'long' }]`，动作写 `cost: [{ resource: '物品次数:滑溜之油' }]`（一件物品有好几种次数，就用 '物品次数:滑溜之油:<短名>'）。

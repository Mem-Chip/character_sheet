修复里比较关键的几处（都有代理实测证据）：

- **哈达之欲**：三个区域各管一个时机（进入挂目盲 / 开始回合 2d6 寒冷 / 结束回合敏捷豁免 2d6 强酸），升环加骰按施放时选的伤害类型走
- **毕格比之手**：挤压骰原来写错（5 环只 3d6，原文 4d6、每高一环 +2d6）；受擒改用官方「受擒」状态 + 逃脱 DC；效应改名避免和专注标记同名抢 `effect()`
- **咒唤林地卫士**：光环改成「施法者身上的效应 + 回合结束触发器」，跟着人走而不是钉在格子
- **沉默术**：去掉了会误删效果的 `within(self, target, 20)`（区域里 `self` 是施法者）
- **火焰刀**：升环骰子改成在效应 state 里记「施放环阶 + 1」（2/3/4 环 = 3d6/4d6/5d6）
- **魅影生物**：妖精召唤术的灵魄数值按最低环（三环）改正（AC 15、1d6+6 + 1d6 力场）
- **链之魔契**：补了「不消耗法术位的召唤动作」，与寻获魔宠共用召唤分组
- **哨兵 / 坚韧复仇 / 战地施法者 / 电爪 / 散兵战术 / 鼓舞之移 / 灵感织衣**：逐条按原文校正触发条件、`endsOn: moved`、反应与诗人激励的扣减
- **契灵复苏**：`setHp` 原来写 `self.hpMax`（会变成宗主的生命值上限），改成 `target.hpMax`

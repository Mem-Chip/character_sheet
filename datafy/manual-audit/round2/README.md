## 顺带发现的引擎缺口（写在 BACKLOG 里了）

1. `aura` 授予的触发器**不检查半径**（`src/combat/triggers.ts` 没用 auraGate）：至圣光轮 30 尺、迅捷灵光 10 尺，
   实测 60 尺 / 20 尺外的生物照样吃伤害、拿加速。
2. **`aura.grant.statics` 根本没被 `effectiveView` 读取**：勇气灵光授予的「免疫恐慌」是死数据（实测照样被恐慌）。
3. `zone` 的 `do` 里拿不到 `vars`（`src/combat/space.ts` 传 `vars: {}`）：施法时 `choose` 选出来的东西（伤害类型等）在区域里丢了。
4. `leftReach` 当场**没法正规花反应**：数据写 `cost: [{ economy: 'reaction' }]` 不扣，玩家可以反复花。
5. `flags.cannot: ['provoke']` 的效应**活到回合结束**，不是「这次移动结束」：得配 `endsOn: moved` 才对（散兵战术踩到了）。
6. **`zone` 不能移动**：只有 createZone / removeZone，没有「区域的『移入生物空间』触发」（月华之光、炽焰法球、自然庇护都卡这条）。
7. `lint` **不检查 `target.size` 的字面量**：圈套术写成 `target.size == 'S'`（引擎里是「小型」）恒假，检查器没报。

## 顺手修的两个引擎问题（都是复核实证出来的）

1. **「黯蚀」和「暗蚀」是同一种伤害**：引擎的 `normType` 只把 `necrotic` / `N` 归一成「暗蚀」，但数据里有 85 处写「黯蚀」
   （官方译名）—— 于是「黯蚀」伤害打在有「暗蚀」抗性的目标身上**不减半**。现在两种写法都归一到同一个类型（`src/combat/damage.ts`）。
2. **`minD20` 只改了 `kept`、没改 `natural`**（序列意识这类「掷出 9 或以下视为 10」）：掷出自然 1 仍按「失手 / 死亡豁免两次失败」结算。
   现在 `recompute()` 里把自然值一起抬上去（`src/combat/d20.ts`）。

这两条一修，原来被复核挑出的 `疫病术`、`脆弱诅咒`、`XPHB:术士:序列意识:14` 直接就能用了（已合并）。

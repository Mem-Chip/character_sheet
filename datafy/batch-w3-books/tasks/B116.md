# 任务 B116：星图

- 条目键：`TCE:德鲁伊:星图:2`
- 出处：德鲁伊 2 级（星辰结社，TCE）

## 原文

2级星辰结社特性
作为你天文学研究的一部分，你创造了一张星图。它是一个微型物体，可以用作你施展德鲁伊法术时的法器。你通过在星图列表上掷骰或选择一个来确定它的形态。当你持握这件星图时，你获得这些好处：
【星图】
| d6 | 星图形态 |
| 1 | 布满星座图列的卷轴 |
| 2 | 钻有细孔的石板 |
| 3 | 斑点枭熊皮，标有凸痕记号 |
| 4 | 一套黑檀木封皮的星图集 |
| 5 | 遇光会投射出星辰轨迹的水晶 |
| 6 | 描绘星座排列的玻璃圆盘 |
当你持握这件星图时，你获得这些好处：
- 你习得戏法 神导术
- 你时刻准备着光导箭这个法术，它对你来说视为一个德鲁伊法术，且不计入你的每日准备法术上限。
- 你可以施展数次光导箭无而无需消耗法术位。其次数等同于你的熟练加值次，在你完成一次长休后你会重获全部已消耗使用次数。
如果你丢失了星图，你可以举行一场为时一小时的仪式来使用魔法创造一个替代品。这一仪式可以在一场短休或长休时举行，并会摧毁先前的星图。

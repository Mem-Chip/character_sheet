# 任务 B252：幽域追踪者魔法

- 条目键：`XGE:游侠:幽域追踪者魔法:3`
- 出处：游侠 3 级（幽域追踪者，XGE）

## 原文

3级起，每当你在此职业达到特定等级时你都能学会一个额外的游侠法术，如幽域追踪者法术表所示的那样。这些法术对你视为游侠法术，且它们不计入你的游侠已知法术总数中。
【幽域追踪者法术】
| 游侠等级 | 法术 |
| 3环 | 易容术 |
| 5环 | 魔绳术 |
| 9th | 恐惧术 |
| 13th | 高等隐形术 |
| 17th | 伪装术 |

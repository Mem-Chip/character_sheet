# 任务 B579：召唤次级恶魔

- 条目键：`XGE:spell:召唤次级恶魔`
- 出处：3 环法术
- 3 环；施法时间：1 动作；距离：60 尺；持续时间：1 小时（专注）

## 原文

你吐出污秽的词语，从无底深渊的无尽混沌中召唤来恶魔。遵从下表掷骰来决定什么生物出现。
| d6 | 被召唤的恶魔 |
|  | 2个挑战等级为1或更低的恶魔 |
|  | 4个挑战等级为1/2或更低的恶魔 |
|  | 8个挑战等级为1/4或更低的恶魔 |
DM 选择恶魔的种类，例如原魔或者怯魔，然后你选择施法距离内可见的未被占据空间让它们出现。被召唤的恶魔在生命值降低为 0 或法术结束时消失。
恶魔对包括你在内的所有生物抱有敌意。它们拥有自己的回合，将它们整体视作一组来投掷先攻。恶魔会花费它的回合用于追逐和攻击最近的非恶魔生物，尽其所能。
作为施放此法术的一部分，你可以使用作为施法材料的血液在地上绘制一个法阵。法阵大到可以包括你在的空间。在法术的持续时间内，被召唤来的恶魔无法穿过或伤害法阵，也无法以其中的任何人作为目标。用这种方式使用的施法材料会在法术结束时被消耗。

## 升环

【升环施法】
当你使用六环或七环的法术位施放该法术时，被召唤的恶魔数量变为两倍。当你使用八环或九环的法术位施放该法术时，被召唤的恶魔数量变为三倍。

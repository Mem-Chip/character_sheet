# 任务 B338：时械魔法

- 条目键：`TCE:术士:时械魔法:1`
- 出处：术士 1 级（时械之魂，TCE）

## 原文

1级时械之魂特性
当你达到相应的术士等级时，你习得下表中的额外法术，如下方时械法术表所示的那样。这些法术对你是术士法术，但不计入你术士已知法术数量。
每当你提升术士等级时，你可以选择一个环数相同的新法术来替换你因此特性习得的一个法术。该法术必须为一个来自术士、魔契师或法师法术列表中的防护法术或变化法术。
【时械法术】
| 术士等级 | 法术 |
| 1环 | 警报术, 防护善恶 |
| 3环 | 援助术, 次等复原术 |
| 5环 | 解除魔法, 防护能量 |
| 7th | 行动自如, 构装召唤术 |
| 9th | 高等复原术, 力场墙 |
此外，你可以从秩序显迹表格中选择或掷骰决定一种你在施法时显现出与秩序之联系的方式。
【秩序显迹】
| d6 | 显迹 |
| 1 | 幽灵般的虚幻齿轮在你身后旋转。 |
| 2 | 时钟的指针出现在你的眼中。 |
| 3 | 你的皮肤发出如黄铜般的金属光泽。 |
| 4 | 你的体表浮动着方程式和几何图形。 |
| 5 | 你的法器短暂地变化成小巧的机械装置。 |
| 6 | 你和那些受到你法术影响的生物都会听到齿轮的滴答声或是钟表的响铃。 |

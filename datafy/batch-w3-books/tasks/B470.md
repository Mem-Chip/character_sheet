# 任务 B470：幻术专家

- 条目键：`AU:幻术专家`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【额外法术】
你的造诣令你始终将特定法术准备就绪。当你具有幻术专家法术表指定环阶的法术位时，你此后始终准备着该环阶及更低环阶对应的法术。
【幻象宗师】
当你使用法术位施展一道来自幻术学派的法术时，你施展该法术时可以无需任意言语、姿势或材料成分，除非该材料成分会被该法术消耗或在法术中具有指定的价值。此外，生物为识破你的法术所创造幻象的真实本质而进行的智力（调查）检定具有劣势。
【幻术专家法术】
| 法术位环阶 | 法术 |
| 1 | 无声幻影 |
| 2 | 魅影之力 |
| 3 | 高等幻影 |
| 4 | 幻景 |
| 5 | 伪装术 |

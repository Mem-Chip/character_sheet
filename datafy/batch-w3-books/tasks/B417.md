# 任务 B417：防护专家

- 条目键：`AU:防护专家`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【额外法术】
你的造诣令你始终将特定法术准备就绪。当你具有防护专家法术表指定环阶的法术位时，你此后始终准备着该环阶及更低环阶对应的法术。
【守护结界】
当你使用法术位施展一道来自防护学派的法术时，你或一名位于你30尺内你可见的生物获得等于所消耗法术位环阶两倍的临时生命值。
【防护专家法术】
| 法术位环阶 | 法术 |
| 1 | 护盾术 |
| 2 | 次等复原术 |
| 3 | 防护能量 |
| 4 | 放逐术 |
| 5 | 群体疗伤术 |

# 任务 B477：死灵专家

- 条目键：`AU:死灵专家`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【额外法术】
你的造诣令你始终将特定法术准备就绪。当你具有死灵专家法术表指定环阶的法术位时，你此后始终准备着该环阶及更低环阶对应的法术。
【操纵生命】
当你使用法术位施展一道来自死灵学派的法术时，你可以立即投掷至多两枚你未消耗的生命值骰。你恢复等于骰值总值加所消耗法术位环阶的生命值。那些生命值骰其后被消耗。
【死灵专家法术】
| 法术位环阶 | 法术 |
| 1 | 致伤术 |
| 2 | 衰弱射线 |
| 3 | 吸血鬼之触 |
| 4 | 枯萎术 |
| 5 | 死者复活 |

# 任务 B493：变化专家

- 条目键：`AU:变化专家`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【额外法术】
你的造诣令你始终将特定法术准备就绪。当你具有变化专家法术表指定环阶的法术位时，你此后始终准备着该环阶及更低环阶对应的法术。
【魔法增幅】
在你的回合内，当你使用法术位施展一道来自变化学派的法术时，你的速度提升等于所消耗法术位环阶五倍的尺数。该提升持续至该回合结束。
【变化专家法术】
| 法术位环阶 | 法术 |
| 1 | 跳跃术 |
| 2 | 蛛行术 |
| 3 | 缓慢术 |
| 4 | 变形术 |
| 5 | 活化物件 |

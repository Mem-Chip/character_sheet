# 任务 B447：预言专家

- 条目键：`AU:预言专家`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【额外法术】
你的造诣令你始终将特定法术准备就绪。当你具有预言专家法术表指定环阶的法术位时，你此后始终准备着该环阶及更低环阶对应的法术。
【先见干预】
当一名位于你60尺内你可见的生物进行D20 检定时，你能以反应令那名生物的那次掷骰获得优势或劣势（由你选择）。
此增益一经使用，直至完成长休你都无法再次使用。当你使用法术位施展一道预言学派的法术时，你也能重获此特性的使用次数。
【预言专家法术】
| 法术位环阶 | 法术 |
| 1 | 侦测善恶 |
| 2 | 心灵尖刺 |
| 3 | 鹰眼术 |
| 4 | 预言术 |
| 5 | 探知术 |

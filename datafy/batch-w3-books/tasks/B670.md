# 任务 B670：制敌术

- 条目键：`FRHoF:spell:制敌术`
- 出处：1 环法术
- 1 环；施法时间：1 动作；距离：60 尺；持续时间：立即

## 原文

你向施法距离内的一名生物掷出一片令其晕眩的魔法力场。目标进行一次体质豁免（构装和亡灵自动豁免成功）。
豁免失败则目标受2d4力场伤害，其速度减半至你的下一回合开始，且目标在其下一回合中仅可以执行一个动作或一个附赠动作（但不能同时执行二者）。豁免成功则仅受半伤。

## 升环

【升环施法】
你使用的法术位每比一环高一环，法术的伤害就增加2d4。

## 可以花的资源（cost 里的 resource 只能用这些 id）

- 没有（法术用法术位，`cost: [{ slot: { min: … } }]`）

## 接口

- 没有主动使用的动作（如果原文里确实有，id 用 `use`）

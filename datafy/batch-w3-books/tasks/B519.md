# 任务 B519：擒拿击

- 条目键：`TCE:擒拿击`
- 出处：可选特性（战斗大师的战技）

## 原文

当你以一次近战攻击命中一名生物时，你能够立即消耗一枚卓越骰，以一个附赠动作对目标进行一次擒抱（见玩家手册的擒抱规则）。将消耗的卓越骰加入你的力量（运动）检定中。

## 职业表（20 级那一行；`classTable('列名')` 读的是角色当前等级那一行）

- 回气：4
- 武器精通：6

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `回气`：回气
- `动作如潮`：动作如潮
- `不屈`：不屈
- `卓越骰`：卓越骰
- `料敌机先`：料敌机先

## 补充

- 战技消耗卓越骰：`cost: [{ resource: '卓越骰' }]`。
- 卓越骰的大小随战士等级变：`cond(self.levelOf('战士') >= 18, 1d12, cond(self.levelOf('战士') >= 10, 1d10, 1d8))`。
- 战技的豁免 DC = 8 + 熟练加值 + 力量或敏捷调整值（取高）：`8 + self.pb + max(self.mod.str, self.mod.dex)`。

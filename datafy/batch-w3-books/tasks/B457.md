# 任务 B457：惑控专家

- 条目键：`AU:惑控专家`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【额外法术】
你的造诣令你始终将特定法术准备就绪。当你具有惑控专家法术表指定环阶的法术位时，你此后始终准备着该环阶及更低环阶对应的法术。
【精妙惑控】
当你使用法术位施展一道来自惑控学派的法术时，你施展该法术时可以无需任意言语、姿势或材料成分，除非该材料成分会被该法术消耗或在法术中具有指定的价值。
【惑控专家法术】
| 法术位环阶 | 法术 |
| 1 | 不谐低语 |
| 2 | 注目术 |
| 3 | 定身类人 |
| 4 | 支配野兽 |
| 5 | 篡改记忆 |

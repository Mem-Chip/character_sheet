## 原文

3级妖精漫游者特性
你在达到特定等级时，你会额外习得一个下方妖精漫游者法术列表中列出的法术。这些法术对你而言视作游侠法术，且不计入你的游侠已知法术数量中。
【妖精漫游者法术】
| 游侠等级 | 法术 |
| 3环 | 魅惑类人 |
| 5环 | 迷踪步 |
| 9th | 解除魔法 |
| 13th | 任意门 |
| 17th | 假象术 |
你还获得了来自一位妖精盟友或一处妖精神力的神奇祝福。你可以在下方妖精荒原之赐表格中选择你的祝福，或者随机决定它。
【精野之赐】
| d6 | 赠礼 |
| 1 | 在你进行长休或短休时，缥缈的蝴蝶在你周身振翅。 |
| 2 | 每天黎明，新鲜的、当季的花朵将在你的头发中生长。 |
| 3 | 你身上有淡淡的肉桂、薰衣草或肉豆蔻，或另一种令人舒适的药草或香料的香味。 |
| 4 | 你的影子会在没人直视它时起舞。 |
| 5 | 你的头发中长出纤细的触角或鹿角。 |
| 6 | 每天黎明，你的肤色和发色会随当前季节的变化而变化。 |

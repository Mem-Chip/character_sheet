# 任务 B445：咒法专家

- 条目键：`AU:咒法专家`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【额外法术】
你的造诣令你始终将特定法术准备就绪。当你具有咒法专家法术表指定环阶的法术位时，你此后始终准备着该环阶及更低环阶对应的法术。
【恒久咒法】
当你为一道来自咒法学派的法术维持专注时，你为维持该专注所进行的体质豁免具有加值。该加值等于你以此专长提升属性的调整值。
【咒法专家法术】
| 法术位环阶 | 法术 |
| 1 | 纠缠术 |
| 2 | 迷踪步 |
| 3 | 咒唤兽群 |
| 4 | 任意门 |
| 5 | 咒唤元素 |

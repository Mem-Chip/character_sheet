# 任务 B492：街头正义

- 条目键：`FRHoF:街头正义`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【锁头】
你的盟友对因你陷入受擒的生物进行的攻击检定具有优势。
【坚固锁结】
当你使用链条、镣铐或绳索捆缚生物时，将你的熟练加入挣脱或破坏该链条、镣铐或绳索的DC中。
【强硬言辞】
你影响生物时，其敌对【态度】态度不会令你的魅力（威吓）检定具有劣势。

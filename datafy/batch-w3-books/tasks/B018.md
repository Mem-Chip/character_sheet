# 任务 B018：神性之怒

- 条目键：`XGE:野蛮人:神性之怒:3`
- 出处：野蛮人 3 级（狂热者道途，XGE）

## 原文

从3级选择此道途时开始，你可以将神性之怒引导至武器攻击中。当你处于狂暴状态时，每回合你的第一次武器攻击命中的生物将受到额外伤害，数值为1d6 + 你野蛮人等级的一半。额外伤害类型为暗蚀或光耀；你获得此特性时选择伤害类型。

## 职业表（20 级那一行；`classTable('列名')` 读的是角色当前等级那一行）

- 狂暴次数：6
- 狂暴伤害：4
- 武器精通：4

## 可以花的资源（cost 里的 resource 只能用这些 id）

- `狂暴`：狂暴次数
- `持久狂暴`：持久狂暴
- `healing-pool`：治疗池
- `frenzied-presence`：狂热威仪
- `神之狂暴`：神之狂暴

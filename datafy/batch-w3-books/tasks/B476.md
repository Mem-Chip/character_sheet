# 任务 B476：迷锁触碰

- 条目键：`FRHoF:迷锁触碰`
- 出处：专长（通用专长）

## 原文

你获得以下增益。
【迷锁守护】
如果一个法术攻击命中你或你在对抗一个法术的豁免检定中失败，你可以采取一个反应反应在密斯特拉之触魔法表格上掷骰以创造一个魔法效应。如果一个效应需要豁免检定，其DC等于8加上由该专长提升的属性调整值和你的熟练熟练加值。
你能够使用此增益的次数等于你的熟练，当你完成长休时重获所有已消耗的使用次数。
【迷锁触碰魔法】
| 1d20 | 效应 |
| 1-2 | 你和每名位于你15尺内的生物进行一次敏捷豁免，豁免失败则受到触发法术环阶1d8的力场伤害，豁免成功则受半伤。 |
| 3-7 | 你和触发法术的施法者建立心灵链接，持续1小时。 |
| 8-10 | 以你为中心半径15尺，高60尺柱状 [效应区域]区域内的重力反转，持续1分钟，如同法术反转重力。 |
| 11-13 | 你和触发法术的施法者均进行一次体质豁免。豁免失败的生物陷入震慑状态直至其下个回合结束。 |
| 14-17 | 你的AC获得+2加值，持续1分钟，若触发法术为法术攻击，则可能使该法术改为失手。 |
| 18-19 | 触发法术的施法者10尺内的任意非魔法易燃物品，只要其未被其他生物着装或携带，均被火焰点燃，受到1d4火焰伤害并开始燃烧。 |
| 20 | 触发法术消散且不产生效应，且用于施展该法术的动作、附赠动作或反应被浪费。若该法术为使用法术位施展的，则该法术位不会被消耗。 |
